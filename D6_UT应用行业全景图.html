UT 应用行业全景图（北极星辰定位版）

客户说"我是做 XX 的"，你 30 秒知道他是不是你的菜。这张图把 UT 市场分成四档：🏆 主场、🤝 机会、⚠️ 边界、🚫 盲区。

📍 这张图为什么重要

前 16 课你学的是技术链：材料→工艺→缺陷→检测方法→自家设备。但客户脑子里是另一条生意链：我的行业→我为什么必须测→谁说了算→掏多少钱。这条图就是两张链的连接点——按行业告诉你"这单做不做、是不是主场"。
看完这张图，你做陌生客户咨询时：先问清材料/工艺/工件/缺陷 → 在脑子里过这张图 → 属于哪一档？→ 主场积极接、机会了解后定、边界说明不是强项、盲区诚实说不做。

〇、★ 先分清 A 扫和 C 扫的"脾气"

客户经常问"你们那个 C 扫和 A 扫到底有啥区别？我到底该用哪个？"——你必须一句话讲清。

A 扫（便携探伤仪）C 扫（水浸成像系统）
本质一维回波信号（幅度 vs 时间）二维缺陷分布图（扫出一个面）
打个比方像"医生用听诊器听一下"——知道有没有毛病像"给工件拍 X 光片"——看到整面毛病分布
解决的问题这一个点有没有缺陷？这一整面有多少缺陷、分布怎样、合格率多少？
擅长焊缝探伤、单点排查、现场抽检、大工件定点结合面质量、分层/脱粘、量产全检、定量评定
设备形态便携、灵活、接触式/手动扫查要扫查机构+水槽，体积大，精度高
判读人工为主（看波形）软件自动成像、出报告
北极星辰定位有产品，但红海市场⭐ 护城河、主场
一句话记忆：A 扫是"找点"（这有没有），C 扫是"画地图"（这整面分布怎样、合格率多少）。

什么时候引导客户上 C 扫？

满足下面任一条，就引导客户考虑 C 扫：
  1. 要的是整面合格率（如钎着率 ≥85%），不是单点有无 → 必须 C 扫
  2. 量产全检、出报告留档 → C 扫自动化更合适
  3. 缺陷是面积型（分层、脱粘、未钎合），不是体积型（气孔）→ C 扫直观
  4. 客户要可追溯、给主机厂交差 → C 扫出图、报告漂亮
  5. 工件批量大、形状规整（板、片、复合件）→ C 扫效率高
反过来——现场在役（容器管道）、焊缝探伤（标准做法）、大工件定点（几米的锻件/转子）、预算有限抽检——A 扫更合适。别为了卖贵的硬推 C 扫，会丢单。

一、🏆 第一档 · 主场（水浸 C 扫量身定做）

这是你的核心市场。客户拿着工件来，大概率就是这档里的。水浸 C 扫在物理尺度（频率、行程、量产能力）和应用经验上有天然优势。

1.1 新能源车 · 动力电池液冷板 ⭐⭐⭐

🧊新能源车水冷板核心主场

👀 工件长这样：一块扁扁的铝板（A4 到 A2 纸大小），里面有弯弯曲曲的流道（冷却液在里面流），上面盖一块盖板，两层之间用钎焊焊死。装在电池包底部，冷却液流过把电池热量带走。

查什么：

  • 钎着率（Brazing Ratio）：两层钎焊后实际焊合的面积比例。主机厂一般要求 ≥85% 或 ≥90%，且单块未焊合区不能太大。
  • 虚焊、脱焊、未钎合（面积型缺陷）
  • 流道堵塞、变形

UT 用法：水浸 C 扫是钎着率检测的金标准（扫出整面结合状态图，软件算比例）。A 扫只能做单点确认，不能定量。

北极星辰定位：⭐⭐⭐ 核心主场，量身定做。设备在行程、扫查效率、软件算钎着率上都有积累。客户群：水冷板制造厂、PACK 厂、电池厂（宁德/比亚迪/国轩/亿纬等的供应商）。
对话要点：客户说"我们要测钎着率"——你直接接：扫查面积多大、节拍要求多少、验收标准看哪个规范。量大的客户关心节拍（每小时测多少块），要强调自动化、上料下料。

1.2 AI / 数据中心 · 液冷散热 ⭐⭐⭐

🖥️AI/数据中心液冷核心主场

👀 工件长这样：和新能源水冷板同源，但更大、更精密。GPU 冷板（一块盖在英伟达 H100/B200 上的铜板或铝板）、CDU（冷量分配单元，像个小冰箱）、Manifold（分液器，把冷却液分到每块 GPU）。

查什么：钎着率、结合质量、流道完整性（同水冷板逻辑，但精度要求更高，散热功率大、温升敏感）。

UT 用法：水浸 C 扫。

北极星辰定位：⭐⭐⭐ 核心主场，且是增长最快的市场。AI 浪潮推动液冷爆发，2024-2026 是建设高峰。客户群：液冷方案商（英维克/曙光/高澜等）、服务器 ODM（浪潮/超聚变）、数据中心业主。
对话要点：AI 客户很多是跨界进液冷新手，要帮他从 0 建立"为什么要测、怎么测"的认知——这正好是教育市场的好机会。铜-铜钎焊比铝-铝衰减大、信号复杂，是技术难点也是差异化机会。

1.3 IGBT / 功率模块散热基板 ⭐⭐⭐

⚡IGBT/功率模块散热基板核心主场

👀 工件长这样：一块铜底板（或铝碳化硅基板），上面焊着 IGBT 芯片，底板和芯片之间有钎焊/烧结层。用在新能源车电控、光伏逆变器、高铁牵引、柔性输电里。

查什么：钎着率 / 烧结层空洞率（散热层有空洞，芯片会局部过热炸机）、分层、脱粘。

UT 用法：水浸 C 扫（基板结合面）。功率模块尺寸够大，20MHz 内能做。

北极星辰定位：⭐⭐⭐ 核心主场。工件规整、批量、要求严，正合 C 扫的胃口。客户群：功率器件厂（斯达/中车时代/比亚迪半导体）、电控厂、光伏逆变器厂。

1.4 溅射靶材 · 结合面 ⭐⭐⭐

🎯溅射靶材结合面核心主场

👀 工件长这样：一块金属圆盘或长方板（比如铜底材上贴一层钛/铝/ITO），用在半导体/PVD 镀膜机里。靶材和背板之间要钎焊结合，结合不好散热就差，镀膜时靶会烧。

查什么：结合面质量（钎着率/脱粘）。

UT 用法：水浸 C 扫。大靶（直径 300mm+、长 1m+）SAM 进不来，正是你的菜。

北极星辰定位：⭐⭐⭐ 细分主场。靶材厂集中（江丰电子、有研、东方钽业等），圈子小，做进去口碑传播快。客户群：靶材厂、PVD 镀膜设备厂、半导体厂。
对话要点：靶材尺寸大、又是单件贵重品，C 扫的"大行程 + 高精度"组合正是差异化。

1.5 复合板 / 爆炸焊 / 轧制复合板 ⭐⭐⭐

🧱复合板/爆炸焊核心主场

👀 工件长这样：两层不同金属贴在一起。比如不锈钢贴在碳钢上（耐腐蚀又便宜）、钛贴在钢上（化工设备用）。复合方法有爆炸复合、轧制复合、钎焊复合。

查什么：结合面质量（未结合区面积比例）。

UT 用法：水浸 C 扫（板件，扫查面积大，C 扫效率高）。

北极星辰定位：⭐⭐⭐ 主场。大板件、面积型缺陷，C 扫经典应用。客户群：复合板厂、化工设备厂、压力容器厂。

1.6 航空航天 · 复合材料 ⭐⭐

✈️航天复材主场（资质门槛）

👀 工件长这样：碳纤维铺层压成的机身蒙皮、机翼壁板、雷达罩（机头那个大圆锥）、蜂窝夹芯板（两层面板中间夹蜂窝纸一样的铝/芳纶）、进气道。

查什么：分层（Layer delamination）、脱粘（Disbond）、孔隙率、冲击损伤（BVID，目视勉强可见的冲击损伤）。

UT 用法：水浸 C 扫（大件、曲面件，扫出整面分层图）—— 你的菜。A 扫/PAUT 做现场在役、外场定检。SAM 做小件实验室取样、高频精细。

北极星辰定位：⭐⭐ 主场但有门槛。技术上 C 扫完全胜任，但航空客户资质要求高（NADCAP / 适航认证 / GJB）、验证周期长、订单碎片化。做进去门槛高但单价高。客户群：主机厂（商飞/成飞/西飞）、复材件供应商、MRO 维修商。
对话要点：航空客户要的是过程稳定 + 报告规范 + 可追溯，不是单看精度。要打进去得先陪他们过验证。

二、🤝 第二档 · 机会行业（能切进去，A/C 扫都有空间）

这档不是核心，但客户来了别推走。A 扫能干的活你也能干，C 扫找到细分点（复材、结合面）就能切入。
行业👀 典型工件查什么UT 用法定位
轨道交通轮对/车轴（锻件）、车体焊缝、复材部件疲劳裂纹、分层A 扫为主，C 扫做复材新造件⭐⭐ 机会
风电叶片（玻纤/碳纤复材）、塔筒焊缝、主轴分层、裂纹A 扫多（焊缝/锻件），C 扫做叶片复材⭐⭐ 机会
光伏逆变器散热器（IGBT）、电池板层压件空洞、脱粘C 扫（逆变器散热同 IGBT 逻辑）⭐⭐ 机会
3C 散热VC 均热板、热管、散热模组、5G 基站壳结合质量、空洞C 扫（件小要定制工装和微型探头）⭐⭐ 机会（要工装）
军工/国防装甲复材、导弹结构件、坦克部件分层、脱粘、裂纹A 扫 + C 扫⭐⭐ 机会（资质门槛）
高压电气（GIS）环氧浇铸绝缘件（盆式绝缘子）、压接接头浇铸气孔、夹杂、裂纹A 扫定点 + C 扫整面定量⭐⭐ 机会
机会行业的共性：不是天然主场，但有复材/结合面/分层这类 C 扫擅长的细分点。客户来了先了解工件细节，能切就切，切不进别强求。

三、⚠️ 第三档 · 边界（能做，但红海或有限制）

这些行业 UT 用得多，但不是北极星辰的强项。能接但不主动主攻，避免陷入价格战。客户问起能做，但要诚实说明不是强项，避免被比价。
行业👀 典型工件查什么UT 用法定位
压力容器/石化球罐、塔器、换热器、管道焊缝焊缝内部缺陷A 扫 + PAUT + TOFD（标准做法）。C 扫用得少⭐ 红海
钢结构/桥梁钢梁焊缝、箱形柱、节点焊缝缺陷A 扫（GB 50205）⭐ 价格战
钢板/钢管厂中厚板分层、无缝钢管分层、纵向/横向裂纹自动化 C 扫（在线多通道）或 A 扫抽检⭐⭐ 有限
铸锻件制造曲轴、连杆、阀门、汽轮机转子缩孔、白点、夹杂、裂纹A 扫为主（粗晶铸件衰减大，C 扫反而差）⭐ 粗晶难
打个比方：压力容器/钢结构就像"菜市场"——人流大但价格透明、竞争激烈、比到几块钱。北极星辰是做"精品店"的，菜市场能搭售但不主攻。把 80% 精力放精品店（第一档主场）。

四、🚫 第四档 · 盲区（要敢说"不做"，诚实是护城河）

敢说"这个我们不做"是五句话哲学的最后一句。诚实标注边界，反而提升信任度——客户下次遇到主场活儿反而更信你。
行业/工件为什么不做建议客户找谁
奥氏体不锈钢焊缝（304/316 焊缝）粗晶+各向异性，UT 杂波大，A/C 扫都难PAUT（相控阵）/ TOFD
精细芯片封装（倒装焊、BGA、亚μm 结合层）要 μm 级分辨率，需 50-230 MHzSAM 超声显微镜（KSI/Sonix/PVA）
长输油气管线（几十公里连续管）便携设备无法连续扫几十公里漏磁内检测 / 导波 / 智能猪（ILI）
钢轨在线探伤（铁路里程）专用化、里程长钢轨探伤车（手推 A 扫可补，非主流）
核电主设备（反应堆、蒸汽发生器）资质门槛极高（HAF601/核安全局）持核级资质的专用厂商
薄壁小径管焊缝（≤30mm 管子）尺度小、规范特殊RT 射线 / PAUT 专用
客户问起盲区怎么回答？（话术模板）

"您这个工件，我们说实话不是强项——奥氏体不锈钢焊缝因为晶粒粗，普通 UT 杂波大，业内标准做法是 PAUT 或 TOFD。我们这边做不了，但可以给您介绍做 PAUT 的厂家 / 或者您这个件有没有别的检测位置我们能帮上忙的？"

——这句话比硬接下单、交付翻车，强一万倍。

六、★ 销售怎么用这张图

场景 1：陌生客户来电"我们能测 XX 吗？"

  1. 先问清材料、工艺、工件尺寸、要查什么缺陷、验收标准
  2. 在脑子里过这张图：属于哪一档？
    • 🏆 主场 → 积极回应，约看工件
    • 🤝 机会 → 回应能做，了解细节后判断投入
    • ⚠️ 边界 → 能做但说明不是强项，避免被比价
    • 🚫 盲区 → 诚实说不做，转介绍

场景 2：做技术交流或方案

  • 主场行业：深挖痛点（钎着率、量产节拍、报告）
  • 边界行业：突出差异化（我们 C 扫 + A 扫组合，不只卖一台）
  • 盲区行业：诚实 + 专业（解释为什么不合适，推荐合适方法）

场景 3：规划销售精力

80% 精力放第一档主场（水冷板 / IGBT / 靶材 / 复合板）
15% 精力放第二档机会（等客户来，不主动开发）
5% 精力搭售第三档（客户顺带问起再接）
0% 精力放第四档盲区（一句话挡掉，转介绍）
记住：会拒绝才是好销售。什么都接的，最后什么都做不好，口碑反而差。北极星辰的护城河是"精品店"定位——把主场打透，盲区转介绍，反而显得专业。

📝 随堂测验（8 题）

UT 应用行业全景图——测验。测完你应该能：分清 A 扫 C 扫、记住四档分类、知道每个行业属于哪档。
1A 扫和 C 扫最本质的区别是？
A. A 扫精度低，C 扫精度高
B. A 扫回答"这点有没有缺陷"，C 扫回答"这整面分布怎样、合格率多少"
C. A 扫用直探头，C 扫用斜探头
D. A 扫测金属，C 扫测复材
✅ 选 B。A 扫是"找点"，C 扫是"画地图"。这是本质区别——不是精度高低，不是探头类型，不是材料区别。客户要钎着率（整面合格率），A 扫做不了，必须 C 扫。
2客户要测水冷板钎着率（要求≥85%），应该上什么设备？
A. 便携 A 扫探伤仪 + 斜探头
B. 射线 RT
C. 水浸 C 扫成像系统
D. 磁粉 MT
✅ 选 C。钎着率是整面合格率指标，必须 C 扫扫出整面分布图、软件算比例。A 扫只能单点查不能定量；RT 对结合面不敏感；MT 只能铁磁材料（铝不行）。这是北极星辰的核心主场。
3下面哪个不属于北极星辰的"🏆 主场"？
A. 新能源车液冷板
B. 溅射靶材结合面
C. 不锈钢-钢复合板结合面
D. 桥梁钢结构焊缝
✅ 选 D。桥梁钢结构焊缝属于⚠️ 第三档边界——A 扫能做但红海、价格敏感、竞争激烈。主场是：水冷板、AI液冷、IGBT散热、靶材、复合板、航天复材。这些共性是"板件+结合面+分层/脱粘+C扫量身定做"。
4客户拿来奥氏体不锈钢（304）焊缝要做 UT 探伤，正确做法？
A. 诚实说明焊缝是难点（粗晶杂波），业内主流用 PAUT/TOFD，坦诚说不做并转介绍
B. 用 10MHz 高频斜探头就行
C. 不锈钢不能测
D. 上水浸 C 扫，没问题
✅ 选 A。奥氏体焊缝是 UT 公认难点（粗晶草状回波），是🚫 盲区。敢说边界是护城河。B 反了（高频衰减更大更糟）；C 太绝对（母材能做）；D 不对（C 扫也解决不了粗晶问题）。
5溅射靶材的检测，为什么 SAM（超声显微镜）进不来，是我们的菜？
A. SAM 价格太贵
B. 大靶（直径 300mm+、长 1m+）尺寸太大，SAM 行程不够；水浸 C 扫大行程+高精度正合适
C. SAM 只能测透明材料
D. SAM 操作太复杂
✅ 选 B。这正是"尺度匹配"护城河——SAM 是精密小件的高频显微镜，大靶材物理上进不来（行程不够、水槽装不下）。北极星辰水浸 C 扫的"大行程 + 高精度"组合正好填补这个缺口。不是价格问题，是物理尺度。
6下面哪个情况，应该引导客户用 A 扫而不是 C 扫？
A. 客户要测水冷板钎着率
B. 客户要测碳纤维板分层，要整面分布图
C. 客户要量产全检、出报告给主机厂
D. 客户要做现场在役的压力容器焊缝抽检
✅ 选 D。现场在役、焊缝抽检是 A 扫的典型场景——便携、灵活、人工扫查。ABC 都是 C 扫的典型场景（整面合格率、分布图、量产全检）。别为卖贵的硬推 C 扫，会丢单。
7压力容器/石化焊缝检测，为什么是"⚠️ 边界"而不是主场？
A. 我们设备做不了
B. 压力容器不需要检测
C. 能做但红海——被奥林巴斯/国产标准机占满，规范严、价格透明、不是差异化主场
D. 压力容器只能用 RT
✅ 选 C。压力容器焊缝是 A 扫最大的市场，我们设备能做，但不是差异化主场——市场被奥林巴斯、汕头/武汉中科等标准机占满，规范严（NB/T 47013）、价格透明。除非客户顺带要 C 扫，否则别主攻，避免被比价。
8【综合题】销售精力应该怎么分配？
A. 80% 主场（水冷板/IGBT/靶材/复合板）+ 15% 机会 + 5% 边界 + 0% 盲区
B. 平均分配到所有行业
C. 80% 放压力容器钢结构（市场最大）
D. 80% 放盲区，因为没人竞争
✅ 选 A。这是"精品店"战略——把主场打透，盲区转介绍。B 平均主义是错的（精力分散啥都做不好）；C 反了（最大市场≠最赚钱，红海反而利润薄）；D 完全错（盲区是技术物理上做不了，不是没竞争）。
