一、钢的分类与牌号——听懂客户嘴里的"Q345R"

客户报价时最常说一串字母数字："这是 Q345R 的"、"用 304 焊的"、"45 号钢轴"。这节教你怎么听懂。

1.1 钢的四种分类法（先有个全貌）

分类法怎么分举例
按碳含量低碳 <0.25% / 中碳 0.25–0.6% / 高碳 >0.6%低碳：Q235、压力容器钢；高碳：弹簧、刀具
按合金元素碳素钢 / 低合金钢（<5%）/ 高合金钢（>10%）碳素：20钢；高合金：不锈钢
按室温组织铁素体钢 / 奥氏体钢 / 马氏体钢 / 双相钢奥氏体：304（UT 难）；双相：2205
按用途（最常用）结构钢/压力容器钢/锅炉钢/不锈钢/工具钢/轴承钢...结构：Q235；容器：Q345R
工程上最常用的是"按用途分"，因为客户报的就是用途牌号。下面专门讲怎么读。

1.2 牌号怎么读（看到就能猜个八九不离十）

① 碳素结构钢："Q + 数字" = 屈服强度

Q = 屈服（Qu）的首字母，数字 = 屈服强度（MPa），数字越大越强。
牌号含义用途UT 难度
Q235屈服 235 MPa，最普通的结构钢（旧牌号 A3）建筑、桥梁、一般钢结构✅ 优
Q345屈服 345 MPa（旧牌号 16Mn），比 Q235 强 40%桥梁、起重机、压力容器✅ 优
Q390/Q420/Q460更高强度的结构钢高层建筑、大跨度✅ 优

② 压力容器钢："Q + 数字 + R" = 屈服 + 容器

R = "容"（Rong）的首字母。带 R 的就是压力容器专用钢，冶炼纯净度高、可焊性好、韧性好。
牌号对应用途
Q245R≈ 20 钢容器版中低压压力容器
Q345R≈ Q345 容器版（最常用容器钢）绝大多数压力容器
Q370R更高强度容器钢大型容器
15CrMoR / 12Cr2Mo1RCr-Mo 耐热容器钢高温容器（炼油、加氢）
客户对话：客户："我们是做压力容器的，材质 Q345R。"
你心里立刻反应：Q345R = 最常见的容器钢，铁素体+珠光体细晶，UT 极好检。可以接："Q345R 是常规容器钢，UT 完全没问题，便携 A 扫能做焊缝，水浸 C 扫能扫板材分层。按 NB/T 47013 标准走就行。"

③ 优质碳素钢："两位数字" = 碳含量的万分之几

数字直接告诉你碳含量。20 钢 = 碳 0.20%，45 钢 = 碳 0.45%。万分之几的记法。
牌号碳含量用途特点
20 钢0.20%（低碳）钢管、锅炉管、渗碳件塑性好、可焊性好
45 钢0.45%（中碳）最常用的调质钢：轴、齿轮、连杆调质后强度韧性均衡
65 钢0.65%（高碳）弹簧弹性好

④ 合金结构钢："数字 + 元素 + 数字"

牌号含义用途
40Cr碳 0.40% + 铬约 1%轴、齿轮（最常用合金调质钢）
20CrMnTi碳 0.20% + 铬锰钛汽车齿轮（渗碳淬火）
42CrMo碳 0.42% + 铬钼高强度锻件（风电主轴、曲轴）
GCr15轴承钢（G=滚）轴承（高纯净度）

关键规律：声速从高到低大致是——低碳钢 ~5920 m/s（好检）→ 中高碳钢 ~5940–5990（好检）→ 铸钢 ~5800–5920（粗晶，中）→ 奥氏体不锈钢 ~5740–5790（分散严重，难）。但声速是经验值，正式检测前必须用同材料试块校准。

二、不锈钢专题——客户说"304"你该警惕

2.1 不锈钢为什么"不锈"？

核心：含铬量 ≥ 12%。铬会在表面形成一层极薄（3–5 nm）、致密、能自我修复的 Cr₂O₃ 钝化膜，把基体和腐蚀介质隔开。

比喻：钝化膜像健康的皮肤，划破了还能长好。普通钢的氧化皮像湿疹破皮——松散多孔，保护不了。铬是灵魂元素，≥12% 是分界线。

2.2 五大类不锈钢（重点记前两类）

类别代表牌号组织磁性特点UT 难度
① 奥氏体304、316、316L奥氏体（FCC）无磁产量最大、耐蚀好、低温不脆⚠️ 焊缝极难
② 铁素体430、409铁素体（BCC）有磁成本低（不含镍）、耐蚀一般良（晶粒较细）
③ 马氏体410、420、440C马氏体有磁硬、耐磨、耐蚀差、焊接易裂良（查淬火裂纹）
④ 双相2205、2507铁素体+奥氏体各半有磁强度高、抗应力腐蚀好中（比纯奥氏体好）
⑤ 沉淀硬化17-4PH马氏体+析出相有磁强度极高（航空航天）良（锻件细晶）
你只要记住两类：
• 奥氏体（304/316）= 无磁 + UT 焊缝难——客户报这俩要警惕
• 其他四类都有磁性，UT 相对好检

磁性是现场快速鉴别法宝：拿块磁铁吸一下，吸不住的是奥氏体（304/316），要小心。

2.3 ★ 奥氏体不锈钢（304/316）为什么 UT 难检

这是 NDT 工程师必须能给客户讲清楚的"经典难题"。分四层原因：

  1. 晶粒粗大：焊缝和铸态下，晶粒可达数毫米。声波波长（5MHz 钢中约 1.2mm）和晶粒同量级，散射极强。
  2. 各向异性强：焊缝柱状晶沿散热方向生长，声速随方向变 1–5%，声束偏转、定位困难。
  3. 草状回波：晶界散射的杂乱回波像草丛铺满屏幕，把小缺陷信号淹没。
  4. 声衰减大：信号传不远，深部缺陷难发现。横波衰减比纵波更厉害。
👉 行业里的应对策略（客户问起能答）
  • 降低频率：用 1–2 MHz 甚至更低，波长变长，散射减弱（但分辨率也下降）
  • 纵波斜探头（TRL）：纵波衰减比横波小，是奥氏体焊缝的主流方案
  • 相控阵 PAUT / TOFD：聚焦能量提高信噪比，对裂纹特别有效
  • 专用对比试块：必须用同炉号同工艺的试块校准
对我们意味着什么：奥氏体母材（板/管/锻件未焊接）我们 A 扫 + C 扫能做；奥氏体焊缝是难点，常规 A/C 扫不是最优，业内主流用 PAUT/TOFD。坦诚说明即可。
客户对话：客户："我们化工厂管道是 304 不锈钢，焊缝能 UT 吗？"
"304 是奥氏体不锈钢，母材我们 A 扫完全能做（测厚、查腐蚀、查夹杂）。但焊缝因为粗晶和各向异性，常规 UT 信噪比差，业内主流用 PAUT/TOFD。如果您重点是焊缝探伤，我帮您评估下，或者我们看下母材部分能不能先做起来。"

三、铸铁四类——声速差一大截

铸铁 = 碳含量 > 2.11% 的铁碳合金（第 1 课讲过这个分界）。碳太多，只能铸造不能锻造。按石墨形态分四类：

铸铁 vs 钢的区别，就是"碳"以什么形态存在。
钢里的碳溶解或化合得很均匀；铸铁里的碳析出成石墨，像在铁基体里塞了一堆"裂纹"。石墨形态决定铸铁性能——片状最差（像塞了一堆裂纹）、球状最好（像塞了一堆圆球，割裂小）。
类别石墨形态牌号声速 m/sUT 难度用途
① 灰铸铁片状（像裂缝）HT200/HT2504400–5000❌ 差机床床身、井盖、缸体
② 球墨铸铁球状（圆球）QT500/QT6005500–5820⚠️ 中（看球化率）曲轴、齿轮、阀体
③ 可锻铸铁团絮状KTH/KTZ—中管件、农机的薄壁件
④ 蠕墨铸铁蠕虫状（介于片球）RuT5200–5600中柴油机缸盖、排气管
关键规律：
• 石墨形态越接近球状，性能越好，声速越高，越好检
• 灰铸铁片状石墨严重衰减声波（声速低到 4400–5000，比钢低一大截）→ UT 很难
• 球墨铸铁声速和球化率正相关：球化率越高，声速越接近钢 → 可以用声速法测球化率
客户对话：客户："球墨铸铁曲轴能 UT 吗？"
"能。球铁声速 5500–5820，比灰铸铁好检多了。常见的是用声速法测球化率——球化率越高声速越接近钢，低于某个值说明球化不良。常规 A 扫也能查内部缩松、夹渣。您主要想查什么缺陷？"

四、有色金属——铝是我们的黄金客户

4.1 铝及铝合金 ⭐（重点）

铝是我们水浸 C 扫的黄金客户材料：声速高（6300 m/s，比钢还快）、晶粒细、衰减小、UT 极清晰。航空铝、铝型材、汽车铝、水冷板（铝合金）全是。
类别牌号用途UT 难度
工业纯铝1060、1050不太受力的件、导电件✅ 优
变形铝合金2024（硬铝）、7075（超硬铝）、6061、3003航空、汽车、水冷板（3003/6061）✅ 优
铝铸件A356、ADC12发动机缸体、壳体⚠️ 中（缩孔气孔多）
水冷板用铝记忆：
• 3003：钎焊性好，水冷板基材最常用
• 6061：强度高，也用于水冷板和结构件
• 这俩都是我们的主场材料，C 扫查钎着率、A 扫查缺陷都很好做

4.2 钛合金

牌号用途UT 难度
TC4（Ti-6Al-4V）航空发动机叶片、飞机承力件、医疗植入物（钛骨头）✅ 优（细晶，声速 6100–6200）
工业纯钛化工设备、海水淡化✅ 优
钛合金细晶、声速高、UT 极好检。航空钛锻件几乎 100% 要 UT。是我们的优质客户材料。

4.3 铜及铜合金

类别用途UT 难度
纯铜（紫铜）电缆、母排、热交换器⚠️ 中（声速低 4660、粗晶）
黄铜阀门、水管接头、散热器⚠️ 中（声速 4430）
青铜轴承、蜗轮、船舶件⚠️ 中~差（铸态粗晶）
铜的声速低（4400–4660）、晶粒粗，UT 中等难度。尤其铜焊缝和青铜铸件粗晶，要小心。

五、复合材料——我们水浸 C 扫的杀手锏市场

复合材料 = "软基体 + 硬纤维"，就像钢筋混凝土——混凝土（基体）包裹，钢筋（纤维）受力。又轻又强，所以飞机、风机、体育器材用得多。
✈️碳纤维 CFRP⭐ 主场
黑色、有编织纹路、又轻又硬。波音 787、空客 A350 一半机身都是它。F1 赛车、高端自行车。
🌊玻璃钢 GFRP⭐ 主场
白色/浅色。游船船身、风力发电机叶片、冷却塔、储罐。
🐝蜂窝夹芯板⭐ 主场
两层薄面板（铝或碳纤维）中间夹蜂窝。极轻但极刚。飞机地板、机舱内饰、卫星板。
★ 复合材料的缺陷 = 水浸 C 扫的看家本领：
• 分层（一层层分开）→ C 扫出图最直观
• 脱粘（面板和芯子没粘牢）→ 蜂窝板/复合板的核心检测
• 孔隙（成型时残留气泡）
• 冲击损伤 BVID（外表没事里面分层了）

结论：复合材料检测 = 我们水浸 C 扫最核心的杀手锏市场之一。

六、国际牌号对照——客户报 ASTM/JIS 也听得懂

有些客户（外企、合资厂）报的是美国 ASTM、日本 JIS、德国 DIN 牌号。你要能对上国标。

国标 GB美 ASTM日 JIS德 DIN是啥

Q345（16Mn）A572 Gr50SM490S355JR低合金结构钢

记忆窍门：客户说 "304"就是国标 06Cr19Ni10，说 "316L"就是国标 022Cr17Ni12Mo2。这俩最常见，记住就行。其他牌号现场查表。

📋 本课总结（10 条）

  1. Q + 数字 = 屈服强度：Q235、Q345、Q390，数字越大越强。
  2. Q + 数字 + R = 压力容器钢：Q245R、Q345R（最常用容器钢）。
  3. 两位数字 = 碳含量万分之几：20 钢（0.20%）、45 钢（0.45%，最常用调质钢）。
  4. 合金钢 = 数字 + 元素：40Cr、42CrMo、GCr15（轴承钢）。
  5. 不锈钢含铬 ≥12% 才"不锈"，分五大类。奥氏体（304/316）无磁、焊缝难检；其他四类有磁、相对好检。
  6. 304 = 国标 06Cr19Ni10，316L = 国标 022Cr17Ni12Mo2，记住这俩对照。
  7. 铸铁按石墨形态分四类：灰铸铁（片状，UT 差）→ 球墨铸铁（球状，可测球化率）。
  8. 铝 = 我们黄金客户：3003/6061 是水冷板基材，声速高、好检。
  9. 钛合金（TC4）好检，铜合金中等（声速低粗晶）。
  10. 复合材料（碳纤维/玻璃钢/蜂窝）= C 扫杀手锏，查分层/脱粘/孔隙。

📝 随堂测验（8 题）

这 8 题考的是"客户报牌号，你能不能对上号、判断好不好检"。做完整再看解析。
1客户说"这是 Q345R"，请问这是？
A. 普通结构钢，做建筑用
B. 压力容器专用钢（R 代表"容"）
C. 不锈钢
D. 工具钢
✅ 选 B。Q345R = 屈服强度 345 MPa 的压力容器钢（R = "容" Rong 的首字母），是最常用的容器钢，铁素体+珠光体细晶，UT 极好检。Q235 才是普通结构钢（A）。
2"45 钢"中的 45 代表什么？
A. 屈服强度 45 MPa
B. 抗拉强度 45 MPa
C. 碳含量 0.45%（万分之四十五）
D. 硬度 45 HRC
✅ 选 C。优质碳素钢用"两位数字 = 碳含量的万分之几"表示。45 钢 = 碳 0.45%，是最常用的调质钢（轴、齿轮）。20 钢 = 碳 0.20%。Q235 那种才是用屈服强度表示。
3现场快速鉴别"这块是不是奥氏体不锈钢（304/316）"，最简单的方法？
A. 用磁铁吸——吸不住的是奥氏体
B. 看颜色——发亮的是奥氏体
C. 称重量——重的是奥氏体
D. 敲一下听声音
✅ 选 A。奥氏体不锈钢（304/316）无磁性，磁铁吸不住。其他四类不锈钢（铁素体/马氏体/双相/沉淀硬化）都有磁性，能吸住。这是现场最快的鉴别法。
4下列哪种铸铁 UT 相对好检，还能用声速法测球化率？
A. 灰铸铁 HT200
B. 灰铸铁 HT250
C. 球墨铸铁 QT500
D. 都一样难检
✅ 选 C。球墨铸铁声速和球化率正相关（5500–5820 m/s，球化越好越接近钢），可用声速法测球化率。灰铸铁（HT）片状石墨严重衰减声波（声速低到 4400–5000），UT 很难。
5水冷板最常用的铝合金牌号是？
A. 2024（硬铝）
B. 3003（钎焊性好）/ 6061（强度高）
C. 7075（超硬铝）
D. 1060（纯铝）
✅ 选 B。3003 钎焊性好、6061 强度高，这俩是水冷板基材最常用的。2024/7075 是航空硬铝，1060 是纯铝受力件少用。水冷板要钎焊（查钎着率），所以选钎焊性好的 3003。
6客户报"304 不锈钢焊缝探伤"，你应该？
A. 没问题，常规 A 扫就能搞定
B. 304 不能检
C. 调高频率到 10MHz 就行了
D. 说明母材能做、焊缝是难点（粗晶），业内主流用 PAUT/TOFD
✅ 选 D。304 是奥氏体，母材能做，焊缝是难点（粗晶草状回波）。A 错（焊缝难）；B 错（母材能测）；C 完全反了（频率越高衰减越大越糟）。坦诚说明焊缝难点，建议 PAUT/TOFD，是我们的专业做法。
7下列哪个材料，是我们水浸 C 扫的杀手锏市场？
A. 碳纤维复合材料板的分层检测
B. 304 不锈钢焊缝
C. 灰铸铁机床床身
D. 铜合金阀门
✅ 选 A。复合材料分层检测是水浸 C 扫的杀手锏——出图直观、耦合稳定、分辨率高。B（奥氏体焊缝）是盲区；C（灰铸铁）衰减大；D（铜合金）粗晶中等难度。
8【销售场景】客户说"我们是外企，材质按 ASTM A36"，你心里对应的是？
A. 对应国标 304 不锈钢
B. 对应国标 Q235 普通结构钢
C. 对应国标 45 钢
D. 没法对应，得让客户换国标
✅ 选 B。ASTM A36 = 国标 Q235 = 日标 SS400 = 德标 S235JR，都是普通碳素结构钢。常见对照要记住。D 错（不能让客户换标准，是我们要会换算）。
