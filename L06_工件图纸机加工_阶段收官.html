一、典型工件与行业应用（速查）

客户报行业，你脑子里要有画面。下面是 NDT 的主要行业和工件。

1.1 压力容器与管道（石化核心）

工件是啥常见材料查什么标准
压力容器化工厂/炼油厂里存高压气体液体的罐子Q345R/Q245R纵/环焊缝（裂纹、未熔合、气孔）NB/T 47013
锅炉产生蒸汽的（电厂、工业锅炉）20G/15CrMoG焊缝、管接头NB/T 47013
管道输送流体的管子20/无缝管/合金管焊缝（对接环焊缝）GB/T 11345/50369
压力容器主要受压元件（NB/T 47013 检测对象）：筒体、封头、管板、接管、法兰、人孔。这些都要 NDT。

1.2 电力 / 航空 / 钢结构 / 其他

行业典型工件查什么方法
火电锅炉管、汽轮机转子（大锻件）、叶片焊缝、白点、裂纹UT/RT/MT

风电叶片（复材）、塔筒（钢）、主轴（锻）、根部法兰分层、焊缝、白点UT（叶片 C 扫/塔筒 A 扫）
航空发动机叶片（高温合金）、起落架（高强钢）、机身（铝/复材）缩孔、裂纹、分层UT/RT/ET
钢结构桥梁、体育馆骨架、高楼钢梁（H 型钢/箱形）T 形/对接焊缝UT/MT
螺栓紧固件高强度螺栓（风电、桥梁、压力容器）裂纹（最危险）、夹渣UT（纵波/相控阵）
铁路/钢轨钢轨、车轴、车轮轨头核伤、轨腰裂纹UT（专用探伤车）
几个值得记住的点：
• 支柱瓷绝缘子 UT——你们行业有专门的仪器和标准（DL/T 303），是变电站刚需
• 风电叶片（玻璃钢）分层检测——水浸/喷水 C 扫强项，是复材检测的大客户
• 螺栓 UT——高强螺栓裂纹检测，纵波直探头从端面探，是常见检测业务

二、图纸术语基础——看懂客户的图纸和委托单

客户拿图纸/委托单来找你，你能看懂吗？这节让你能读懂 NDT 检测要求。

2.1 机械制图基础（最少要知道）

概念是啥为什么对 NDT 重要
剖视图把工件"切开"看内部截面NDT 委托单常画剖视，标出要检的焊缝/区域
比例图纸尺寸和实际的比例别把 1:2 图纸尺寸当实际尺寸
尺寸公差允许的尺寸偏差范围UT 测厚结果要对照公差判断是否合格
表面粗糙度 Ra表面光滑程度（数字越小越光）UT 探伤要求表面 Ra ≤ 6.3μm，太粗耦合不好
UT 对表面粗糙度的要求：UT 探伤要求表面打磨到一定粗糙度（一般 Ra ≤ 6.3μm）。表面太粗，探头贴合不严，耦合不好，信号会失真。这是现场 UT 的基本功。

2.2 ★ 焊接符号（对 NDT 重要！）

图纸上的焊缝用焊接符号标注。NDT 工程师要能看懂焊缝类型、尺寸，才能知道检什么。
符号要素含义
基准线一条横线，符号画在上面/下面
箭头线指向焊缝位置
基本符号表示焊缝形式：‖（I 形对接）、V（V 形）、△（角焊）、∪（U 形）
补充符号现场焊旗、周围焊圆圈、底部平
尺寸焊脚尺寸（角焊）、坡口角度、根部间隙
检测要求怎么标：图纸上焊缝附近常标 "UT 100% Ⅱ级" 这种。意思：
• UT = 用超声检测
• 100% = 全检（不是抽检）
• Ⅱ级 = 按 GB/T 11345，合格级别是 Ⅱ 级及以上

2.3 ★ 检测委托单解读（销售必读）

检测委托单 = 客户给你的检测任务书。能不能接、怎么报价、怎么出方案，全看委托单读得懂不懂。
必须看懂的项是啥为什么重要
工件名称 + 图号什么工件、哪张图知道检什么
材料牌号Q345R / 304 / 3003 铝等决定声速、频率、能不能测
板厚 / 尺寸多厚、多大决定探头 K 值、方法、扫查面
焊接方法埋弧焊/氩弧焊/...预判缺陷类型
检测标准NB/T 47013 / GB/T 11345按什么标准评
检测比例100% / 20% / 局部全检还是抽检
合格级别Ⅰ/Ⅱ/Ⅲ 级按什么级别验收
检测时机焊后 / PWHT 后 / 表面处理什么时候检（注意延迟裂纹）
读委托单四步法：
① 这是什么工件（材料 + 厚度 + 焊接方法）
② 检什么缺陷（裂纹？气孔？分层？）
③ 怎么检（方法、比例、扫查面）
④ 怎么评（标准、级别）
四步想清楚，方案就出来了。
客户对话：客户发来委托单，标"Q345R，板厚 20mm，埋弧焊，按 NB/T 47013.3 做 UT 100% Ⅱ级，焊后 48 小时"。
你读完心里：压力容器（Q345R），中板（20mm），埋弧焊（厚板焊缝），全检 UT，Ⅱ 级合格，焊后等 48 小时（注意延迟裂纹）。方案：用 5MHz K2 斜探头，从焊缝两侧扫查，覆盖焊缝+HAZ，按 GB/T 11345 Ⅱ 级评。这单我们能做。

三、机加工与热处理（快速带过）

机加工本身不产生内部缺陷，但热处理（尤其淬火）产生的淬火裂纹是常见 UT 对象。

3.1 机加工（了解）

方法是啥做啥件
车削工件转，刀走（车床）轴、圆件、螺纹
铣削刀转，工件走（铣床/加工中心）平面、槽、复杂形状
磨削砂轮磨（磨床）高精度表面、量具
钻/镗钻孔/扩孔孔类
机加工不改变材料内部组织，只切外形。所以机加工件本身没有内部缺陷（除非加工前的热处理或锻造铸造成型的缺陷）。

3.2 ★ 淬火裂纹（常见 UT 对象）

淬火 = 把钢加热到高温（奥氏体），快速冷却（水/油），得到硬而脆的马氏体。淬火让钢变硬，但冷却太快会产生巨大内应力，把钢从内部或表面撕出裂纹——这就是淬火裂纹。
★ 淬火裂纹的特征：
• 多在截面突变处（尖角、孔边、台阶）——应力集中
• 常在表面或近表面，也可能内部
• 表面开口用 MT/PT 查；内部用 UT 查
• 常见工件：淬火齿轮、轴承、弹簧、模具、工具钢件
淬火裂纹 vs 焊接冷裂纹：都是"冷裂纹"，但来源不同。淬火裂纹来自热处理冷却；焊接冷裂纹来自焊接 HAZ 冷却 + 氢。两者都是内应力撕裂，但检测时机和位置不同。

3.3 焊后热处理（PWHT）—— 焊缝检测绕不开

PWHT = 焊后把焊缝再加热到某一温度保温，缓冷。目的：消除焊接残余应力 + 让淬硬组织回火变韧 + 让氢扩散出来。
PWHT 对检测的影响（重要）：
• PWHT 能让延迟裂纹充分形成 → 所以 PWHT 后检测时机好
• 但 PWHT 可能产生再热裂纹（SR 裂纹） → 所以 PWHT 后要重新检测
• 客户说"做过 PWHT 了"，你心里要响铃：可能要重新检，查再热裂纹

🎉 第一阶段（懂对象）完成！

学完前 6 课，你已经具备完整的"懂工件"能力：

材料（组织/牌号）→ 工艺（铸/轧/锻/焊）→ 工件（容器/管道/叶片/水冷板）→ 图纸（符号/委托单）→ 缺陷预判（白点/分层/裂纹/钎着率）

客户拿工件来，你能听懂他说什么、知道检什么、配得出方法。这就是"懂对象"。

📝 随堂测验（8 题）

这 8 题考工件、图纸、热处理的基础认知。做完整再看解析。
1压力容器焊缝检测最常用的标准是？
A. GB/T 11345
B. NB/T 47013（承压设备无损检测）
C. GB/T 3323
D. ASME
✅ 选 B。NB/T 47013是承压设备（压力容器/锅炉/管道）无损检测的权威国标，涵盖 UT/RT/MT/PT/ET 全套。GB/T 11345 是焊缝 UT 专用标准（NB/T 47013 会引用它）。压力容器客户必引 NB/T 47013。
2委托单上标"UT 100% Ⅱ级"，意思是？
A. 检测仪器准确度 100%，Ⅱ级精度
B. 检测人员 Ⅱ 级资格，全检
C. 超声全检（不是抽检），合格级别 Ⅱ 级及以上
D. 工件 100% 是 Ⅱ 级钢
✅ 选 C。"UT 100% Ⅱ级"：① UT = 超声检测 ② 100% = 全检（非抽检）③ Ⅱ级 = 按 GB/T 11345 评定，合格级别是 Ⅱ 级及以上（Ⅰ级最好）。这是委托单最常见的标注，必须看懂。
3淬火裂纹最常见的位置是？
A. 截面突变处（尖角、孔边、台阶）——应力集中
B. 工件正中心
C. 表面光滑处
D. 随机分布
✅ 选 A。淬火裂纹来自冷却内应力，应力集中在截面突变处（尖角、孔边、台阶、壁厚突变），所以裂纹多在这些位置。UT/MT 查淬火件时，重点扫这些区域。
4客户说"焊缝做过 PWHT 了"，你心里应该想到？
A. 检测可以省了
B. PWHT 后焊缝肯定没问题
C. 只能做 RT 不能做 UT 了
D. PWHT 可能产生再热裂纹，要重新检测；但延迟裂纹也已充分形成，检测时机反而是好的
✅ 选 D。PWHT（焊后热处理）影响检测：① 可能产生再热裂纹（SR 裂纹），所以要重新检；② 但 PWHT 让延迟裂纹充分形成，所以检测时机反而好。A/B 太天真；C 完全错。
5UT 探伤对工件表面有什么要求？
A. 必须抛光镜面
B. 表面粗糙度 Ra ≤ 6.3μm，太粗耦合不好
C. 表面越粗越好
D. 没要求
✅ 选 B。UT 探伤要求表面打磨到 Ra ≤ 6.3μm（一般）。表面太粗，探头贴合不严，耦合剂填不平，信号失真。这是现场 UT 基本功。但也不必抛光镜面（A 过度）。
6风电叶片（玻璃钢复合材料）分层检测，我们用什么设备合适？
A. 水浸 C 扫 / 喷水 C 扫（复材分层是强项）
B. 只能 RT
C. 磁粉 MT
D. 涡流 ET
✅ 选 A。风电叶片是玻璃钢（复材），分层检测是水浸/喷水 C 扫的强项。C 错（MT 只能铁磁材料，玻璃钢不行）；D 错（ET 只能导电表面，玻璃钢不行）；B 太绝对（RT 能做但 C 扫更合适大面积扫查）。
7读检测委托单的四步法顺序是？
A. 怎么评 → 检什么 → 怎么检 → 什么工件
B. 怎么检 → 怎么评 → 什么工件 → 检什么
C. 什么工件（材料/厚度/焊法）→ 检什么缺陷 → 怎么检（方法/比例）→ 怎么评（标准/级别）
D. 随便看
✅ 选 C。四步法：① 什么工件（材料+厚度+焊接方法）→ ② 检什么缺陷（裂纹/气孔/分层）→ ③ 怎么检（方法+比例+扫查面）→ ④ 怎么评（标准+级别）。四步想清，方案就出来了。
8【销售场景】客户说"我是做钢结构的，T 形焊缝"，你的方案思路？
A. 直接报价，不管细节
B. 建议换对接焊缝
C. 只能 RT
D. 问板厚/材料/验收标准，配 K 值斜探头 UT + 表面 MT，按 GB/T 11345 评
✅ 选 D。钢结构 T 形焊缝是常见场景。专业做法：先问清板厚（决定 K 值）、材料（选频率）、验收标准（评级）；配斜探头 UT 查内部 + MT 查表面，按 GB/T 11345 评。钢结构常引 GB 50205 或 GB/T 11345。
