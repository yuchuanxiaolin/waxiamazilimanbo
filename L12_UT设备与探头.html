UT 设备与探头

探头选错了，再贵的仪器也白搭。这一课讲清"客户拿来一个工件，到底配什么探头、什么试块"——这是销售的核心动作。

一、UT 设备（仪器）

1.1 探伤仪是怎么工作的

探伤仪就像一个"会说话、会听回声"的 bats（蝙蝠）。它发射电路给晶片一个高压脉冲 → 晶片振动发声音（电→声）→ 声波进工件遇到缺陷/底面反射回来 → 晶片收到变成电信号（声→电）→ 仪器放大、数字化、显示成波形。
步骤做什么关键参数
同步电路全机节拍器，定脉冲重复频率 PRF典型 100~1000 Hz
发射电路产生高压窄脉冲激励晶片决定声脉冲强度
接收放大回波电压只有 mV 甚至 μV 级，要放 60~100 dB动态范围 ≥26 dB（基本）
检波 + A/D + DSP整流→数字化→峰值保持/闸门报警/波形存储A/D 位数决定动态范围
A/D 位数 = 仪器档次的重要指标：8 位（≈48dB，淘汰）、10 位（≈60dB，中端）、12 位（≈72dB，主流）、14~16 位（≈84~96dB，高端）。位数越高，强回波（始脉冲）和弱回波（底面附近小缺陷）能同时看清，不"溢出"。

1.2 两类主力设备（你卖的）

设备类型干什么典型产品客户场景
便携 A 扫探伤仪手持现场，显示 A 型波形（心电图样），人工手持探头扫查北极星辰等便携式数字探伤仪焊缝现场检测、管道测厚、锻件抽查、在役巡检
水浸 C 扫系统工件浸水槽，探头 X-Y 自动扫查，输出彩色"俯拍地图"北极星辰 BSN-C 系列水浸 C 扫复合材料分层、涡轮叶片壁厚、管材/板材自动化、精密零件
★ 一句话分清两种设备：
• 便携 A 扫 = "现场应急、人拿着扫、看波形数波高"——灵活、便宜、适合现场；
• 水浸 C 扫 = "实验室自动化、扫出彩色地图、能成像存档"——稳定、精密、适合形状规则件和复材。
客户对话：客户："我就查一根焊缝管道，用得着水浸 C 扫吗？"
"焊缝现场检测便携 A 扫就够了，人拿斜探头沿着焊缝走，快又灵活。水浸 C 扫的强项是复合材料分层、涡轮叶片壁厚这种要成像、要存档、要自动化的，您这管道没必要上 C 扫。但要是您那批是碳纤维复材件查脱粘分层，那就非水浸 C 扫不可了。"

二、探头（UT 的"枪头"，最关键）

2.1 探头结构与压电效应

探头就是 UT 的"枪头"——仪器是枪身，探头决定打什么弹、打多准。压电效应是核心：给压电材料加电压它会振（电→声，发射），压它一下会产生电压（声→电，接收）。同一块晶片既能发射又能接收，这是脉冲反射法的基础。
部件材料作用
晶片PZT 锆钛酸铅（压电陶瓷）核心元件。厚度决定频率（f ≈ c_片/2×厚度），大小决定声场
阻尼块环氧+钨粉吸收背面声波、减少余振 → 脉冲变窄、盲区变小（代价：灵敏度略降）
匹配层Z 介于晶片(~30)和工件(46)之间降低界面反射损失，提高声能传输效率
保护膜氧化铝、硬质合金耐磨保护晶片。越薄越灵敏但越不耐磨——权衡
★ 一句话记住探头四件套：晶片发声音，阻尼清余振，匹配层传得进，保护膜防磨损。客户拆探头时能背出这四个零件，立刻显专业。

2.2 探头类型（按工况选——销售必须背熟）

探头类型波型/原理主要用途典型工件
直探头纵波，垂直入射锻件/钢板内部缺陷、测厚、查分层大锻件（转子、曲轴）、钢板、轴类
斜探头横波（斜楔折射）焊缝检测（最主）、管材、螺栓对接焊缝、管节点焊缝
双晶探头（T-R）一发一收两晶片，声束在工件内"交汇"成焦点区测薄壁（可测 1mm 以下）、近表面缺陷薄壁管道测厚、带氧化皮管
聚焦探头透镜或曲面晶片让声束聚焦特定深度小缺陷、水浸 C 扫标配管材、复材水浸、精密件
表面波探头斜楔角=第二临界角，产生表面波表面开口裂纹工件表面、焊趾裂纹
爬波探头入射角≈第一临界角，近表面纵波皮下 1~9mm 近表面缺陷堆焊层、近表面检
水浸探头工件浸水，探头不直接接触可聚焦、可自动化、不磨损探头管材、复材 C 扫、精密件
测厚探头双晶接触式，高频 5~10MHz配测厚仪专用管道、压力容器壁厚
★ 三大主力（必须秒答）：
• 直探头（纵波） → 锻件/钢板/测厚/分层
• 斜探头（横波，带 K 值） → 焊缝
• 双晶探头（一发一收） → 薄壁测厚 + 近表面
为什么双晶能测薄壁：单探头自发自收时，发射脉冲（几百伏）会"塞住"接收前级，造成近区盲区（3~5mm 起测）。双晶的接收晶片不参与发射，没有发射脉冲干扰，能测 1mm 以下的薄壁。这就是测厚仪几乎都用双晶的原因。
客户对话：客户："我这管子带氧化皮，测厚总是不准。"
"单晶直探头对氧化皮、凹凸面很敏感，耦合不好就不准。换双晶测厚探头：它两片晶片一发一收，焦点区灵敏度高，对表面状态不敏感，带氧化皮的管子也能稳定测。配我们便携探伤仪的测厚模式就行。"

三、探头参数怎么选（落到销售动作）

3.1 频率与晶片尺寸

参数选大的选小的
频率 f高频 5~10MHz：细晶/薄件/小缺陷，分辨率高低频 0.5~2MHz：粗晶/铸件/厚件/衰减大，穿透深
晶片尺寸 D大晶片：近场长、指向性好 → 厚大锻件小晶片：近场短、盲区小 → 薄件、需小盲区
★ 频率经验口诀：
• 焊缝通用：2~5 MHz
• 奥氏体焊缝（粗晶）：降到 1~2 MHz（减草状回波）
• 细晶锻钢：5~10 MHz
• 铸件（粗晶衰减大）：0.5~2 MHz
• 测厚：5~10 MHz 双晶

3.2 K 值（斜探头的折射角，焊缝核心参数）

K = tanβ（β 是横波在钢里的折射角）。K 值决定声束斜进工件的角度，直接影响能扫到哪种走向的缺陷。
K 值折射角 β适合什么
K145°厚壁焊缝，厚度方向取向缺陷（未熔合、未焊透），声程短衰减小
K1.556°厚壁焊缝常用
K263°中等厚度焊缝（10~40mm），综合检出率好，最常用
K2.568°薄壁焊缝、垂直取向裂纹
K372°薄壁焊缝、垂直裂纹
★ 焊缝 K 值速记：厚壁选 K1~K1.5，中壁选 K2 或 K2.5，薄壁选 K2.5~K3。重要焊缝常用两种 K 值互补检测，提高不同取向缺陷的检出率。有机玻璃→钢 K 值范围对应入射角 27.6°~57.7°。
客户对话：客户："我这是 20mm 厚的对接焊缝，配什么 K 值？"
"20mm 是典型的中等厚度，配 K2（63°）斜探头最合适，综合检出率最好。要是焊缝质量等级高，建议再加一个 K1 或 K2.5 互补，把不同走向的未熔合、裂纹都能扫到。频率配 4MHz 或 5MHz，晶片 9×9 或 13×13。"

四、试块——UT 的"度量衡"（没有试块=检测不可信）

试块就是 UT 的"砝码和尺子"。仪器显示的波高、深度、K 值，全靠试块校准。没有试块校准的 UT 检测，结果不可信，客户也不能认。
试块含什么反射体干什么用
CSK-IA（IIW1 国内版）R100/R50 圆弧、φ50 孔、φ1.5 横孔、刻度槽测斜探头入射点、K 值，校水平/深度基线，校验仪器线性
CSK-IIA（横孔试块）不同深度的 φ2×40 长横孔制作 DAC 曲线（距离-波幅曲线），设定焊缝检测灵敏度
CSK-IIIA（槽型试块）矩形槽评定焊缝表面附近缺陷
RB 系列（日本 JIS）横孔（RB-1/2/3）同 CSK-IIA，日标体系
★ 销售铁律：每次检测前必须用试块复核入射点和 K 值（探头磨损会变）。K 值漂移 → 定位全错。客户买仪器时试块是必备配件，不能省。便携现场常用 CSK-IA（小巧），做 DAC 必备 CSK-IIA。
★ 校准的本质：调仪器的"声速"（定横轴比例）和"探头零点"（消除斜楔/保护膜/耦合层的声程偏移），让屏幕读数 = 工件实际位置。校准用的是 CSK-IA 上已知声程的 R100 圆弧。
客户对话：客户："你们仪器这么贵，试块能不能送一个就行？"
"试块是 UT 的度量衡，缺一不可。CSK-IA 是校 K 值和入射点的（每次检测前必用），CSK-IIA 是做 DAC 曲线、定灵敏度的（焊缝检测必用）。少一个，您这焊缝检测的灵敏度和定量就没法定，出报告都没底气。建议两块都配齐，这是标准配置。"

五、销售核心：客户拿来工件怎么配探头

★ 三步配探头法（销售动作）：
第一步：问工件——什么材料？多厚？什么形状？查什么缺陷（内/表/焊缝）？
第二步：定波型+探头类型——内部/测厚→直探头或双晶；焊缝→斜探头；复材/精密件→水浸聚焦。
第三步：定参数——频率（看材料和厚度）、晶片尺寸（看厚度）、K 值（看焊缝厚度）。最后配试块。
客户场景配什么
20mm 对接焊缝，碳钢K2 斜探头，4~5MHz，9×9 或 13×13，配 CSK-IA + CSK-IIA
100mm 厚大锻件，查内部夹杂直探头，2~5MHz，φ20~φ30 大晶片（指向性好）
薄壁管（3mm）测厚，带氧化皮双晶测厚探头，7~10MHz
奥氏体不锈钢焊缝斜探头，降到 1~2MHz（减草状回波），K2
碳纤维复合材料查分层水浸 C 扫 + 聚焦探头（BSN-C 系列），5~10MHz
焊趾表面裂纹表面波探头
涡轮叶片测壁厚（精密、要成像）水浸聚焦 C 扫，高频
★ 销售心法：客户说"我要测 XX"，别急着报型号。先问材料、厚度、缺陷类型、是否要存档成像。这四问答完，配什么探头、要不要上 C 扫，自然就清楚了——这才是顾问式销售。

📝 随堂测验（6 题）

UT 设备与探头。客户拿来工件配什么——这一课的核心。
1焊缝 UT 检测最常用的探头是？
A. 直探头（纵波）
B. 双晶探头
C. 斜探头（横波，带 K 值）
D. 表面波探头
✅ 选 C。焊缝有余高，直探头放不上；斜探头声束斜着进，从两侧扫查能覆盖焊缝和 HAZ 整个截面，是焊缝 UT 的标准做法。直探头用于锻件/钢板/测厚。
2双晶探头（T-R）为什么能测 1mm 以下的薄壁？
A. 接收晶片不参与发射，没有发射脉冲干扰，消除了近区盲区
B. 双晶频率更高
C. 双晶晶片更大
D. 双晶用了特殊耦合剂
✅ 选 A。单探头自发自收时发射脉冲（几百伏）会"塞住"接收前级，造成 3~5mm 近区盲区。双晶接收晶片不参与发射，没有发射脉冲干扰，所以能测薄壁和近表面。这就是测厚仪几乎都用双晶的原因。
320mm 厚的碳钢对接焊缝，配什么 K 值斜探头最合适？
A. K1（45°）
B. K2（63°）
C. K3（72°）
D. 不用 K 值
✅ 选 B。20mm 属中等厚度焊缝，K2（63°）综合检出率最好，最常用。厚壁选 K1~K1.5（声程短衰减小），薄壁选 K2.5~K3。重要焊缝常用两种 K 值互补检测。
4CSK-IIA 试块（φ2 横孔）的主要用途是？
A. 测斜探头入射点
B. 校验仪器线性
C. 测 K 值
D. 制作 DAC 曲线、设定焊缝检测灵敏度
✅ 选 D。CSK-IIA 含不同深度的 φ2×40 长横孔，是做 DAC 距离-波幅曲线、定灵敏度用的。测入射点/K 值/校线性是 CSK-IA（IIW1）的活。两者都是焊缝 UT 必备。
5水浸 C 扫描系统（如 BSN-C 系列）最适合检测什么？
A. 复合材料分层、涡轮叶片壁厚、需要成像存档的精密件
B. 长输管道现场焊缝巡检
C. 高温在役管道测厚
D. 铸件粗晶内部大面积筛查
✅ 选 A。水浸 C 扫的强项是可聚焦、可自动化、耦合稳定、能成像存档，适合复材分层、叶片壁厚、管材板材自动化。现场焊缝巡检用便携 A 扫；高温在役用 EMAT 或高温耦合剂；粗晶铸件衰减大需低频接触法。
6【销售场景】客户拿来一根带氧化皮的薄壁管道要测厚，老测不准，你应该推荐？
A. 换更高频的单晶直探头
B. 上水浸 C 扫系统
C. 双晶测厚探头（5~10MHz），对表面状态不敏感，焦点区灵敏度高
D. 表面波探头
✅ 选 C。带氧化皮的薄壁管，单晶直探头耦合差、近区盲区大。双晶测厚探头一发一收，焦点区灵敏度高，对表面状态不敏感，是这种工况的标准方案。C 扫太重没必要；表面波探头是查表面裂纹的不是测厚的。
