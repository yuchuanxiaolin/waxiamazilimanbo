UT 检测方法与评定

怎么扫、扫出什么图、怎么判缺陷大小和级别。再讲清 TOFD 和 PAUT 这两个高端卖点——客户常问，答得专业立刻拉开档次。

一、UT 检测方法的分类

UT 方法从不同角度分类，理解分类才能针对客户工况选对方法。

1.1 按原理分类（核心三种）

原理怎么干优点缺点/用途
脉冲反射法（最常用）单探头自发自收，靠回波到达时间（→位置）和幅度（→大小）判缺陷灵敏度高、能定位、能定量有近场盲区、对面取向缺陷敏感；90% 的 UT 都是它
穿透法双探头分置工件两侧，一发一收，靠透射声能衰减判缺陷无盲区、适合衰减大的材料不能定位深度、对探头对中敏感；复合材料常用
共振法连续波扫频，厚度=n×λ/2 时共振—主要用于测厚（多被脉冲反射法取代）
★ 一句话：脉冲反射法是 UT 绝对主力（便携 A 扫、焊缝、测厚都是它）；穿透法专攻复合材料（衰减大、脉冲反射回不来）；共振法基本只剩测厚。客户问"你们仪器什么原理"，答"脉冲反射法"九成没错。

1.2 按耦合方式分类（决定用便携还是水浸）

耦合方式怎么干优点缺点/用途
接触法探头+薄层耦合剂直接压工件设备简单、灵活、现场方便耦合一致性差、表面要打磨、效率低；便携 A 扫
液浸法（水浸法）工件浸水槽，探头在水中间隔水层耦合稳定、可聚焦、可自动化、不磨损探头工件必须可浸水、水层声程补偿复杂；水浸 C 扫
充水法（水柱法）探头和工件间用水柱/水膜耦合，不整体浸入避免浸大件，又能稳定耦合管材/板材自动检测、轮式探头
耦合方式怎么记：接触法="贴脸"（探头直接压工件，现场便携）；水浸法="泡澡"（工件整个浸水里，实验室 C 扫）；充水法="浇水"（中间夹水柱，介于两者之间，自动线常用）。
客户对话：客户："复合材料分层你们能测吗？"
"复材衰减大，脉冲反射法回波弱，常规便携 A 扫不太行。我们用水浸 C 扫 + 穿透法：两个探头一上一水下浸，靠透射声能衰减查分层和脱粘，还能扫出彩色 C 型图存档。这正是我们 BSN-C 水浸 C 扫的强项。"

二、显示方式（A/B/C/D 型——看懂屏幕在画什么）

★ 一句话类比（必背）：
• A 型 = 心电图（横轴时间→深度，纵轴波幅）
• B 型 = 切片照片（横轴探头位置，纵轴深度，亮度=波幅）
• C 型 = 俯拍地图（横纵轴都是 X-Y 平面坐标，亮度=某深度闸门内波幅）
• D 型 = 侧拍照片（类似 B 型但视角不同，TOFD/PAUT 常用）
显示横/纵轴信息量谁用
A 型横=时间(声程/深度)，纵=幅度单点信息，最基础所有 UT 探伤仪都有，便携 A 扫标准显示
B 型横=探头位置，纵=声程(深度)，亮度=幅度工件纵截面的缺陷分布类似医用 B 超，PAUT/水浸
C 型横纵=扫查平面 X-Y，亮度=特定深度闸门内波幅某深度层面的"切片图"水浸 C 扫、复材分层
D 型类似 B 型，声程投影方向不同侧视截面TOFD、PAUT
★ 销售：便携 A 扫只能出 A 型波形（数波高、看深度）；水浸 C 扫能出彩色 C 型地图 + B 型切片，这就是为什么复材、精密件客户愿意多花钱上 C 扫——能成像、能存档、客户/监理能直观看。

三、DAC 曲线和 AVG 曲线（UT 定量的两件法宝）

远处的小缺陷和近处的大缺陷，回波可能一样高——怎么判断谁更大？得用曲线补偿距离效应。这就是 DAC 和 AVG 的意义。

3.1 DAC 曲线（距离-波幅曲线，焊缝 UT 核心）

★ DAC 制作原理：相同尺寸反射体（如 φ2 横孔），声程越远回波越弱。把"相同反射体、不同声程"的回波最高点连成线，就是基准 DAC 线。
三条线（GB/T 11345 焊缝 UT 的核心）：在基准 DAC 线基础上派生——
• 判废线 RL = 基准 DAC 线（φ2 当量）→ 回波≥此线 = 不合格
• 定量线 SL = 基准线下移 6 dB → 落在此线以上 = 需记录定量
• 评定线 EL = 基准线下移 12~14 dB → 落在此线以上 = 开始评定
三条线把屏幕分成"评定区/定量区/判废区"。检测灵敏度就设在评定线。
★ CSK-IIA 试块就是做 DAC 用的（不同深度 φ2 横孔）。做 DAC = 设灵敏度 + 定量评级依据。焊缝 UT 没有 DAC 曲线，定量就没底气。横孔对孔径不敏感（直径加倍只 +3dB），便于不同声程保持一致。

3.2 AVG / DGS 曲线（平底孔当量，锻件常用）

AVG = 距离-增益-大小（德语）/ DGS（英语）。基于平底孔（圆盘反射体）的理论公式，建立"声程-回波幅度-平底孔当量"三者关系。理论性强、可公式推导，不像 DAC 纯实测。现代数字探伤仪内置 AVG，直接显示"缺陷当量平底孔尺寸"。
★ AVG 的适用边界（重要）：理论公式仅在远场有效，理想工作区是 s ≥ 3N（三倍近场区之外）。近场区（0~N）声场起伏公式不成立；过渡区（N~3N）偏差大；3N 以外理论值和实测高度一致。所以 DGS 定量要求声程 ≥ 3N。
项目DAC 曲线AVG(DGS) 曲线
反射体模型横孔（实测）平底孔（理论计算）
数据来源实测试块理论公式 + 探头参数
适用范围任意声程远场（s ≥ 3N）
主要用途焊缝（GB/JIS 体系）锻件（欧标体系）
客户对话：客户："DAC 和 AVG 有什么区别？"
"DAC 是实测横孔做的，针对具体工件，焊缝 UT 用得多（配 CSK-IIA 试块做曲线）；AVG 是理论公式算的平底孔当量，锻件 UT 用得多，仪器内置直接出当量尺寸，但要求声程在 3 倍近场以外才准。您做焊缝走 DAC，做锻件走 AVG，就这么分。"

四、缺陷评定（定位、定量、定性、定级）

★ 评缺陷四步：先定位（在哪）→ 再定量（多大）→ 然后定性（什么性质）→ 最后定级（合格不合格）。

4.1 定位（确定缺陷三维位置）

斜探头几何关系（必记）：
• 水平距离 l = K × 深度 d
• 声程 s = d × √(1+K²)
例：K2 探头，深度 20mm 的缺陷，水平距离 40mm，声程 ≈ 44.7mm。
定位法分三种：声程法 / 水平法 / 深度法，焊缝 UT 最常用深度法（屏幕直接显示深度）。

4.2 定量（确定缺陷大小）

方法适用怎么干
当量法点状/小缺陷（<声束截面）与已知反射体（平底孔/横孔）回波比较，找"回波相等"的尺寸作为当量。AVG/DAC 都属此类
测长法（6dB 法/半波高法）面积大于声束的缺陷找最高回波，移探头使回波降 6dB（声压减半），两个 -6dB 点间距 = 缺陷指示长度
20dB 法声束较窄时-20dB 点间距减去声束宽度 = 缺陷长度
端点反射法长条缺陷（裂纹）测两端点反射
★ 6dB 法口诀：回波最高点 → 移到回波掉一半（-6dB） → 左右两点距离 = 缺陷长度。这是测大面积缺陷长度的标准动作。

4.3 定性（判断缺陷性质）和定级

★ 定性是 UT 最难的环节：传统 A 超不像射线能直接看到缺陷形状，主要靠经验 + 综合判断。
• 尖锐单一回波 → 平面型（裂纹、未熔合、未焊透）
• 多脉冲丛状回波 → 体积型（气孔群、夹渣）
• 动态波形平缓变化 → 大面积缺陷；剧烈瞬间出现消失 → 小点状气孔
• 结合焊接工艺位置：根部→未熔合/咬边；中心→气孔/夹渣/裂纹；HAZ→冷裂纹；焊趾→疲劳裂纹。
PAUT + TFM 成像能直接看出缺陷形状，定性比传统 A 超强得多。
定级：按 GB/T 11345 等标准，依据缺陷回波幅度（落在评定/定量/判废哪个区）+ 指示长度 + 性质，判 Ⅰ / Ⅱ / Ⅲ 级（Ⅰ 级最高，合格；Ⅲ 级以下不合格，具体按客户验收标准）。

五、TOFD 和 PAUT（高端卖点——客户常问）

这两个是 UT 销售中客户最爱问、最显专业的部分。每种都要能说清"原理、能干什么、不能干什么"。

5.1 TOFD（衍射时差法）

普通 UT 靠缺陷反射回波；TOFD 靠缺陷尖端的衍射波（声波扫过缺陷尖端时，尖端像个小喇叭向四面八方发波）。
原理：一对纵波斜探头（45°~70°）对称放焊缝两侧，一发一收。探头沿焊缝走，得到"位置-深度"灰度图（D 扫）。图谱上依次出现：直通波（表面零点）→ 缺陷上尖端衍射波 → 缺陷下尖端衍射波 → 底波。
★ TOFD 的杀手锏：上下尖端衍射波的时间差 = 缺陷高度，定量精度可达 ±1mm，优于传统 UT 和 PAUT。且上下尖端波相位相反（差 180°），是识别两者的关键特征。
TOFD 优点TOFD 缺点
缺陷高度定量极精确（±1mm）；检测快（一次扫查覆盖全壁厚）；不依赖缺陷取向；数据可永久存档；能测近垂直裂纹（传统 UT 盲区）直通波和底波附近有盲区（上表面 2~5mm，下表面 1~3mm），需 PAUT/脉冲反射补充；对粗晶衰减敏感；数据解读要求高；设备贵
应用：核电站、厚壁压力容器焊缝（厚度 ≥12mm）、在役检测。常和 PAUT 配套用（PAUT 补盲区，TOFD 补定量精度）。

5.2 PAUT（相控阵超声——最热的高端技术）

普通 UT 探头只有一个晶片、一个固定方向，像手电筒照一个点；PAUT 探头有几十上百个独立小晶片，每个晶片发射时间能精确控制（延迟），像可以电子转向和聚焦的探照灯——不用机械动，声束就能扇形扫、任意深度聚焦。
★ PAUT 原理核心：探头由多个独立晶片（16/32/64/128 阵元）排成阵列，每个阵元激励时间可控延迟（聚焦法则 Focal Law），实现：
• 电子偏转声束方向（不用机械转）
• 电子聚焦（任意深度聚焦）
• 动态聚焦（沿声束多点聚焦）
扫查模式怎么扫用途
扇形扫查（S-scan）同一发射点，按不同角度（30°~70°，步进 1°）依次发射焊缝 UT 最常用，一次放置覆盖多角度，像医用彩超
线性电子扫查（E-scan）同角度、不同位置的虚拟探头依次激活等效多探头并排快速扫
聚焦扫查改变聚焦深度不同深度获最佳灵敏度
★ PAUT 优点：一次扫查覆盖大角度范围（效率高）；可电子聚焦（灵敏度高）；可成像（B/C/D 型）便于定性；数据可存储可重现；探头小型化适合复杂几何（管座、三通）。
缺点：设备/探头/软件贵；对人员要求高（要会设计聚焦法则）；粗晶仍受限；大角度偏转时侧向分辨率下降。

5.3 PAUT vs 传统 UT vs TOFD（客户必问对比）

对比项传统 UT（A 扫）PAUTTOFD
探头单晶片，固定方向多阵元阵列，电子转向一对纵波斜探头
成像只有波形（A 型）B/C/D 型彩色成像D 扫灰度图
定量精度一般较好最高（高度 ±1mm）
效率低（人工逐点扫）高（一次扇形扫）高（一次扫覆盖全壁厚）
盲区近场盲区有，但可补偿上下表面有盲区
价格便宜贵贵
客户对话（高频问题）：客户："PAUT 和普通 UT 到底有啥区别？贵那么多值吗？"
"普通 UT 就一个晶片、一个固定角度，像手电筒照一点，得人拿着来回扫，只出波形。PAUT 是几十个晶片阵列，电子控制声束扇形扫和任意深度聚焦，不用机械动就能一次覆盖 30°~70° 全角度，还能出彩色 B/C 成像，缺陷长什么样直接看到。所以：检焊缝效率高好几倍、定性准、数据能存档给监理看。要是您做的是压力容器、长输管道这种大批量、要出正式报告的，PAUT 值；要是偶尔查几道焊缝，便携 A 扫就够。"
客户对话（进阶）：客户："那 TOFD 又是啥？和 PAUT 啥关系？"
"TOFD 靠缺陷尖端的衍射波测缺陷高度，精度能做到 ±1mm，是三者里最高的，核电站、厚壁容器爱用它。但它上下表面有盲区。所以高端项目常PAUT + TOFD 配套：PAUT 补盲区、看出形状，TOFD 精确量高度——强强联合，这也是我们高端方案的卖点。"

📝 随堂测验（6 题）

UT 检测方法与评定。DAC/AVG、缺陷评定、TOFD/PAUT——客户常问的高端话题。
1UT 检测中 90% 都用的是哪种原理？
A. 脉冲反射法（单探头自发自收，靠回波时间和幅度判缺陷）
B. 穿透法（双探头一发一收，靠透射衰减判缺陷）
C. 共振法
D. 衍射法
✅ 选 A。脉冲反射法灵敏度高、能定位能定量，是 UT 绝对主力（便携 A 扫、焊缝、测厚都是它）。穿透法专攻复合材料（衰减大回不来）；共振法基本只剩测厚；衍射法是 TOFD 的原理。
2DAC 曲线中，"判废线、定量线、评定线"三条线的关系是？
A. 三条线一样高
B. 评定线最高，判废线最低
C. 判废线=基准DAC线，定量线下移6dB，评定线下移12~14dB（评定线最严、最低）
D. 随便画三条平行线
✅ 选 C。判废线 RL=基准 DAC 线（φ2 当量），回波≥此线不合格；定量线 SL 下移 6dB，需记录定量；评定线 EL 下移 12~14dB（最低最严），开始评定。检测灵敏度设在评定线。
3测缺陷指示长度用的"6dB 法（半波高法）"是怎么操作的？
A. 把回波调到屏幕 6dB 高度
B. 找最高回波点，移探头使回波下降6dB（声压减半），两个-6dB点间距=缺陷指示长度
C. 给仪器加 6dB 增益
D. 用 6mm 的探头扫
✅ 选 B。6dB 法（半波高法）用于面积大于声束的缺陷：找最高回波 → 移探头使回波降 6dB（声压减半）→ 左右两个 -6dB 点之间距离 = 缺陷指示长度。这是测大面积缺陷长度的标准动作。
4关于 C 型显示（C-scan），正确的是？
A. 横轴是时间，纵轴是波幅（那是 A 型）
B. 只能用于接触法便携检测
C. 显示的是工件纵截面（那是 B 型）
D. 横纵轴是扫查平面X-Y坐标，亮度=特定深度闸门内回波幅度，是某深度的"俯拍地图"
✅ 选 D。C 型显示横纵轴都是 X-Y 平面坐标，亮度表示某深度闸门内的回波幅度，相当于某深度层面的"俯拍地图"。广泛用于水浸 C 扫、复材分层检测。便携 A 扫只能出 A 型波形。
5TOFD（衍射时差法）最突出的优势是？
A. 缺陷高度定量精度极高（±1mm），优于传统UT和PAUT
B. 设备最便宜
C. 没有任何盲区
D. 只能测表面缺陷
✅ 选 A。TOFD 靠缺陷尖端衍射波，上下尖端波时间差=缺陷高度，精度±1mm，是三者里最高的。缺点是直通波和底波附近有盲区（上表面2~5mm、下表面1~3mm），常和 PAUT 配套互补。设备贵。
6【销售场景】客户问"PAUT 和普通 UT 有啥区别，值不值贵那么多"，你怎么答？
A. "没区别，就是贵点好看"
B. "PAUT 只能测薄板"
C. "PAUT是阵列多晶片电子转向+聚焦，一次扇形扫覆盖大角度范围还能出彩色成像，效率高、定性准、能存档；大批量要正式报告的值，偶尔查几道焊缝便携A扫就够"
D. "PAUT 已经淘汰普通 UT 了"
✅ 选 C。PAUT 多阵元电子控制声束扇形扫+任意深度聚焦，一次覆盖 30°~70° 全角度，出 B/C 彩色成像，效率高、定性准、数据能存档。压力容器/长输管道等大批量要正式报告的场景值得；偶尔查几道焊缝便携 A 扫就够。按客户工况判断，才是专业顾问。
