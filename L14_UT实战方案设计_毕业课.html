扫盲课 · 第三阶段 · 第 14 课（毕业课）

UT 实战方案设计

这是把前 13 课串起来的"毕业课"——客户给工件，你怎么问、怎么配、怎么报价、怎么出方案。这是销售的核心动作。

📍 这节课为什么是"毕业课"

前 13 课你学了材料、工艺、缺陷、检测方法、仪器、探头、评定。这节课把它们串成一条线——客户拿工件来，你从"问什么"到"出方案"，走完整流程。
这节课没有新理论，全是实战动作。五个典型案例覆盖你日常 90% 的客户咨询。

一、★ 方案设计六步法（销售标准动作）

① 问工件
→
② 问缺陷
→
③ 选方法
→
④ 配探头
→
⑤ 定等级
→
⑥ 报价
步骤问什么/做什么为什么
① 问工件材料牌号？板厚/尺寸？焊接方法？什么工件？决定声速、频率、能不能测
② 问缺陷查什么缺陷？裂纹？气孔？分层？钎着率？决定方法选型（UT/RT/MT/PT）
③ 选方法内部还是表面？面状还是体积型？什么材料？按方法选型决策树（第10课）
④ 配探头频率？直/斜探头？K值？晶片尺寸？试块？按工件厚度/缺陷配（第12课）
⑤ 定等级按什么标准？合格级别？检测比例？时机？按委托单/标准（第16课）
⑥ 报价设备型号/检测服务？工时？试块？差旅？出报价单
关键：六步走完，方案就出来了。不要跳步骤——跳了就容易漏信息、配错探头、报错价。

二、★ 五个实战案例（覆盖 90% 客户场景）

案例 1：压力容器焊缝（最常见）

🏛️Q345R 压力容器焊缝A 扫

客户咨询："我们做压力容器的，Q345R，板厚 20mm，埋弧焊，按 NB/T 47013 做 UT 100% Ⅱ级。"

你的六步：

  • ① 工件：Q345R（铁素体+珠光体细晶，UT 优），20mm 中板，埋弧焊（厚板焊缝）
  • ② 缺陷：焊缝内部缺陷（裂纹、未熔合、未焊透、气孔、夹渣）
  • ③ 方法：UT 横波斜探头（焊缝标准做法）+ 建议 RT 配合（体积缺陷）+ MT 查表面
  • ④ 探头：5MHz，K2 斜探头（20mm 用 K2 合适），CSK-IIIA 试块校准
  • ⑤ 等级：按 GB/T 11345（NB/T 47013.3 引用），Ⅱ 级合格，100% 全检
  • ⑥ 时机：焊后等 24–48 小时（延迟裂纹）

设备：便携 A 扫探伤仪 + 5MHz K2 斜探头 + CSK-IIIA 试块。我们能做。

案例 2：钢板分层检测

📜轧制钢板分层A 扫/C 扫

客户咨询："我们进了一批钢板，要做分层检测。"

你的六步：

  • ① 工件：钢板（材料？厚度？），轧制态
  • ② 缺陷：分层（钢板头号缺陷）
  • ③ 方法：UT 纵波直探头（分层是 UT 一等一绝活）
  • ④ 探头：5MHz 双晶直探头（双晶减小近场盲区）或单晶直探头；按 GB/T 2970 扫查
  • ⑤ 等级：按 GB/T 2970 或 EN 10160 评级
  • ⑥ 方案：中厚板出厂 100% 扫分层。量大/大板可上水浸 C 扫自动化

设备：便携 A 扫（少量）或水浸 C 扫（大批量/大板）。我们都能做。

案例 3：锻件白点检测

🔧42CrMo 锻件白点A 扫

客户咨询："这是 42CrMo 锻件，要查白点。"

你的六步：

  • ① 工件：42CrMo（合金调质钢，锻后细晶，UT 优），锻件
  • ② 缺陷：白点（氢致圆片状内部裂纹）+ 夹杂
  • ③ 方法：UT 纵波直探头（白点是直探头克星）
  • ④ 探头：5MHz 直探头，大面积扫查（锻件 100% 查白点）
  • ⑤ 等级：按 GB/T 6402（锻件 UT）或客户标准
  • ⑥ 关键提醒：检测时机必须在锻件冷却+热处理后（白点是延迟的，热的查不到）

设备：便携 A 扫 + 5MHz 直探头。我们能做。

案例 4：★ 水冷板钎着率（核心市场）

🧊新能源/水冷板钎着率水浸 C 扫

客户咨询："我们做电池液冷板，怎么证明钎焊质量？"

你的六步：

  • ① 工件：铝合金水冷板（3003/6061），真空钎焊或 FSW
  • ② 缺陷：钎着率（焊实比例）、虚焊、空洞、流道堵塞
  • ③ 方法：水浸 C 扫（平板+铝+查结合面=C 扫量身定做）
  • ④ 探头：高频聚焦探头（15–25MHz，查精细钎焊面），水浸耦合
  • ⑤ 等级：按客户标准（车厂/数据中心，常见钎着率≥85%）
  • ⑥ 核心卖点：软件自动扣除流道面积，直接算钎着率百分比，出 C 扫分布图

设备：水浸 C 扫（BSN-C 系列）。这是我们的核心市场。

案例 5：★ 复合材料分层（杀手锏）

✈️碳纤维/玻璃钢分层水浸 C 扫

客户咨询："碳纤维板怎么查分层？"

你的六步：

  • ① 工件：碳纤维/玻璃钢/蜂窝板（复材）
  • ② 缺陷：分层、脱粘、孔隙、冲击损伤 BVID
  • ③ 方法：水浸 C 扫（复材分层=C 扫看家本领）
  • ④ 探头：聚焦探头（5–15MHz），水浸或喷水耦合
  • ⑤ 等级：按航空标准（如空客/波音规范）或客户标准
  • ⑥ 方案：扫一张俯视热力图，分层面积位置一目了然

设备：水浸 C 扫或喷水 C 扫（大件用 BSN-CT400 喷水式）。这是我们的杀手锏市场。

不能做的案例（要敢说不）：奥氏体不锈钢焊缝探伤（粗晶，建议 PAUT）、十几米长钢管（建议漏磁/导波）、半导体芯片封装（要 SAM）。坦诚转介比硬接专业。

三、报价要素（卖设备 vs 做检测服务）

你两种业务都做，报价逻辑不同：

要素卖设备做检测服务
核心设备型号 + 探头 + 试块 + 软件 + 培训 + 售后工时 + 探头耗材 + 试块 + 差旅 + 报告
报价单位按套按米（焊缝）/按件/按平米/按天
关键变量行程大小、通道数、自动化程度、软件功能工件量、复杂度、现场条件、标准要求
试块客户另购或赠送包含在检测费里
报价必问清单：
① 工件详情（材料/厚度/尺寸/数量）
② 检测要求（方法/标准/级别/比例）
③ 现场/实验室（要不要上门）
④ 工期（什么时候要）
⑤ 预算（客户接受范围）
⑥ 验收方式（谁验收、怎么验收）

四、★ 方案设计模板（销售照着填）

给客户的检测方案书，标准结构：
  1. 工件信息：名称、材料、板厚、尺寸、数量、焊接方法
  2. 检测目的：查什么缺陷
  3. 检测标准：引用哪个标准（NB/T 47013、GB/T 11345 等）
  4. 检测方法：UT（A 扫/C 扫）/RT/MT/PT，比例（100%/抽检）
  5. 设备配置：仪器型号、探头（频率/K值/晶片）、试块
  6. 验收等级：合格级别（如 Ⅱ 级）
  7. 检测时机：焊后/PWHT 后/表面处理后
  8. 报价：设备费 or 检测服务费（按单位）
  9. 交付物：检测报告（含 C 扫图/缺陷记录）
把这个模板存成文档，每次客户咨询照着填，方案几分钟就出来。

📝 随堂测验（6 题）

UT 实战方案设计——毕业课测验。
1客户咨询压力容器焊缝检测，方案设计第一步应该？
A. 直接报价
B. 选探头
C. 问工件（材料/厚度/焊法/标准）
D. 寄设备
✅ 选 C。方案设计六步法第一步是"问工件"——材料牌号（决定声速/频率）、板厚（决定 K 值）、焊接方法（预判缺陷）、标准（决定验收）。信息不全不能报价，否则容易配错探头报错价。
220mm 厚 Q345R 焊缝，标准探头配置是？
A. 5MHz，K2 斜探头 + CSK-IIIA 试块
B. 2MHz 直探头
C. 10MHz 表面波探头
D. 1MHz 低频探头
✅ 选 A。20mm 中板焊缝用 5MHz K2 斜探头（K2 适合中壁 10–40mm），CSK-IIIA 试块是焊缝 UT 标准试块。直探头不能测焊缝（有余高）；表面波只查表面；1MHz 太低分辨率不够。
3水冷板钎着率检测，我们用的核心设备是？
A. 便携 A 扫
B. 水浸 C 扫（BSN-C 系列）
C. 射线 RT
D. 磁粉 MT
✅ 选 B。水冷板是水浸 C 扫量身定做的市场：平板+铝+查结合面+要出图+量产。便携 A 扫出不了钎着率分布图；RT 对结合面不敏感；MT 只能铁磁（铝不行）。
4客户拿来一批钢板要查分层，最佳方案？
A. 射线 RT
B. 磁粉 MT
C. 涡流 ET
D. UT 纵波直探头（分层绝活），量大上水浸 C 扫自动化
✅ 选 D。分层是 UT 直探头的一等一绝活（平行板面大反射面，回波极强）。少量用便携 A 扫，大批量/大板上水浸 C 扫自动化。RT 对分层不敏感（厚度方向重叠）。
5锻件白点检测，最关键的提醒是？
A. 用高频探头
B. 表面要抛光
C. 检测时机必须在冷却+热处理后（白点延迟形成，热的查不到）
D. 只能用 RT
✅ 选 C。白点是氢致延迟裂纹，热的锻件白点还没形成，立即检测会漏检。必须冷却到室温 + 等够时间（最好热处理后），让白点充分形成。这是锻件检测最关键的提醒。
6【毕业题】客户拿来奥氏体不锈钢焊缝要 UT 探伤，你的专业回应？
A. 说明母材能做、焊缝是难点（粗晶），业内主流用 PAUT/TOFD；坦诚说明我们的边界
B. 没问题，常规 A 扫就能搞定
C. 不锈钢不能测
D. 用 10MHz 高频就行
✅ 选 A。这是敢说边界的体现。奥氏体焊缝是 UT 公认难点（粗晶草状回波），常规 A/C 扫不是最优，业内主流用 PAUT/TOFD。母材能做，焊缝坦诚说明——这才是专业销售。B 太轻率；C 太绝对；D 完全反了（高频衰减更大更糟）。
