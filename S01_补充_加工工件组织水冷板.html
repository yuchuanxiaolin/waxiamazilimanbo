一、材料是怎么造出来的：五大加工方式

客户拿来一个工件，它一定是用下面某一种（或几种）方式造出来的。知道"怎么造的"，就能预判"可能有什么缺陷"。

1.1 先用一句话记住五大加工

加工方式一句话理解通俗比喻
铸造把金属化成水，倒进模具凝固像做冰棍：倒进模具冻硬
轧制把金属从两个辊子中间挤过去，压扁/压长像擀面杖擀面
锻造把烧红的金属用锤子砸成想要的形状像铁匠打铁
机加工用刀具从毛坯上切下多余的料像木工雕刻
焊接把两块金属边缘熔化，让它们长在一起像用胶水粘，但是用高温"焊"在一起

1.2 每种加工详解 + 产生什么缺陷

🏭铸造（Casting）液态成型
把金属熔化成液体，倒进砂型或金属模具里，冷却凝固成零件。
阀门壳体、发动机缸体、下水道井盖、机床床身、磨球、水暖管件。
铸造件的缺陷：缩孔（金属凝固收缩留下的洞）、气孔（气泡没跑掉）、夹杂（杂质卷进去）。铸件内部组织是粗大的柱状晶，UT 衰减大，比较难检。
📜轧制（Rolling）固态成型
把烧红的钢锭从两个旋转的辊子中间挤过去，越挤越薄/越细。钢板、钢管、钢轨都是这么来的。
钢板（造船、容器、桥梁）、钢管（输油输气）、H 型钢（建筑）、钢轨（铁路）。
轧制件的缺陷：分层（钢板最危险的缺陷，就是内部一层层分开，这正是 UT 直探头的拿手好戏）、折叠（表面被压折进去）。
🔨锻造（Forging）固态成型
把金属烧红，用锤子（或压力机）反复砸，砸成想要的形状。同时把内部组织砸细、砸密实。所以锻件性能比铸件好得多。
汽车曲轴、连杆、齿轮、风电主轴、航空起落架、高铁车轴、模具。
锻件的缺陷：白点（氢造成的内部微裂纹，是锻件最可怕的隐患）、夹杂、折叠。锻件晶粒被砸细，UT 很好检。
⚙️机加工（Machining）切削成型
用车床、铣床、磨床等，从铸造或锻造的"毛坯"上切掉多余的料，加工成精确尺寸的零件。机加工不改变材料内部组织，只是切外形。
任何有精确尺寸要求的零件：轴、齿轮、螺纹、法兰面、模具型腔。
机加工相关的缺陷：本身不产生内部缺陷，但加工前的热处理（淬火）可能产生淬火裂纹——这是常见 UT 检测对象。
🔥焊接（Welding）连接成型
把两块金属的边缘用高温熔化，让它们熔合在一起，冷却后连成一个整体。这是工业中最常用的连接方式，也是 UT 检测的第一大客户场景。
压力容器焊缝、管道焊缝、船体、桥梁、钢结构、汽车车身。
焊缝的缺陷（UT 主战场）：裂纹（最危险）、未熔合、未焊透、气孔、夹渣。焊缝内部组织是粗大柱状晶，比母材难检，尤其是不锈钢焊缝。
记住这条因果链：
铸造 → 缩孔/气孔
轧制 → 分层
锻造 → 白点/夹杂
焊接 → 裂纹/未熔合/气孔
热处理 → 淬火裂纹
客户说"我是铸件/锻件/焊缝"，你脑子里就该蹦出对应的缺陷。

2.2 铝合金工件（你们常检）⭐

铝是你们水浸 C 扫描的重点客户材料。铝件常见有这几类：

🛩️航空铝板/铝锻件
飞机蒙皮（机身外壳）、机翼结构件、航空支架。航空对缺陷零容忍，几乎100% 要 UT 检测。
飞机机身那层银白色的金属皮、机翼内部骨架。
📱铝型材
窗户框、门框那种有固定截面形状的铝材。建筑、电子产品外壳大量使用。
窗户的铝合金边框、笔记本电脑外壳。
🚗汽车铝合金件
新能源车为了减重，大量用铝合金——车身板、电池壳、轮毂。
汽车轮毂（那个亮亮的轮子）、新能源车电池包底板。
铝的 UT 特点：声速高（6300 m/s，比钢还快）、晶粒细、衰减小、UT 非常好检。主要查：氧化膜夹杂、缩孔（铸铝件）、偏析。铝是你们水浸 C 扫的黄金客户。

2.3 复合材料工件（你们常检）⭐⭐

什么是复合材料？就像钢筋混凝土——混凝土（基体）负责包裹，钢筋（增强体）负责受力。复合材料也是这个思路："软的基体 + 硬的纤维"，取两者之长。又轻又强，所以飞机、风机上用得越来越多。
✈️碳纤维复合材料（CFRP）
黑色、有编织纹路、又轻又硬。现代飞机机身（波音 787、空客 A350 一半机身都是碳纤维）、F1 赛车、高端自行车、羽毛球拍。
黑色带编织花纹的板子、高端自行车架。
🌊玻璃钢（GFRP）
玻璃纤维 + 树脂。白色或浅色。游船船身、风力发电机叶片、冷却塔、储罐、化工厂管道。
游船白色船壳、风车那三片大叶子、化工厂外的玻璃钢储罐。
🐝蜂窝夹芯结构
两层薄面板（铝或碳纤维）中间夹一层蜂窝（铝箔或纸）。极轻但极刚。飞机地板、机舱内饰、卫星太阳翼板、高铁车厢。
像夹心饼干，切开看中间是六角形蜂窝孔。
★ 复合材料的缺陷 + 水浸 C 扫 = 天作之合
复合材料最怕的缺陷是：分层（一层层分开）、脱粘（面板和芯子没粘牢）、孔隙（成型时残留气泡）、冲击损伤（被砸了，外表没事里面分层了，叫 BVID）。

这些缺陷正是水浸 C 扫描的看家本领——C 扫能扫出一张"俯视热力图"，分层在哪、面积多大、脱粘在哪个位置，一目了然。

结论：复合材料检测 = 你们水浸 C 扫最核心的杀手锏市场。

2.4 水冷板/液冷板 ⭐⭐⭐（你们这几年的核心案例）

这是你们近两年最主要的检测市场——新能源车和 AI 数据中心爆发带火的黄金赛道，而且正好命中水浸 C 扫的所有强项。务必吃透。

（1）水冷板是什么

一句话：两片金属板焊在一起，中间刻着蜿蜒的流道，通冷却液给发热件散热。
本质是"板内藏管"——就像地暖地板，表面是平整的地板，下面埋着热水管路。水冷板也是：表面平整，内部是弯弯曲曲的冷却液通道。
🧊水冷板（液冷板 / Cold Plate）⭐⭐⭐ 核心市场
发热件（电池/芯片）贴在水冷板表面，冷却液在内部流道循环带走热量。
一块平整的金属板，表面有进/出水嘴接头，内部有看不见的流道。

（2）两大爆发市场（客户就在这两个行业）

🔋
新能源车水冷板
动力电池包液冷板——每块电池下面那张散热板，防止电池热失控
🤖
AI/数据中心液冷板
GPU 服务器液冷板——AI 训练功耗爆表，风冷扛不住，液冷成刚需
☀️
光伏/储能
逆变器、储能电池的散热板
⚡
IGBT/功率模块
电机控制器、充电桩里的散热基板

（3）材料和工艺（决定要查什么）

项目说明对 UT 的影响
材料主要是铝合金：3003（钎焊性好）、6061（强度高）。也有少量铜、不锈钢✅ 铝声速高、晶粒细，水浸 C 扫最好检的材料之一
工艺①真空钎焊两片铝板中间夹钎料（Al-Si 系如 4004），真空炉高温熔化钎料把两片焊在一起查钎着率、虚焊、空洞
工艺②搅拌摩擦焊 FSW用高速旋转的搅拌头把两片板边缘"搅"在一起，不加钎料、不熔化（固态焊）查未焊透、根部缺陷

（4）★ UT 要查的核心（销售必背）

检测对象通俗讲为什么重要
钎着率钎焊面"焊实的比例"——比如焊了 85%，剩 15% 是虚焊/空洞水冷板最核心的指标。虚焊区散热差→电池/芯片过热→热失控/宕机
虚焊/空洞本该焊牢的地方没焊上，留了气隙空气导热远不如金属，一处空洞就是一处"散热死角"
流道堵塞钎焊时钎料流进流道，把冷却液通道堵了堵了冷却液不流通→整块板散热失效
脱层两层板在使用中脱开会导致泄漏和散热失效
为什么钎着率这么关键？
想象一块水冷板钎着率只有 60%——意思是 40% 的面积没焊牢。这 40% 的区域，热量传不过去，相当于这块板"瘸了"。电池在那个区域会局部过热，轻则寿命缩短，重则热失控起火。所以车厂和数据中心对钎着率有硬指标（常见要求 ≥85% 或更高，看客户标准）。

（5）★ 为什么水冷板是你们水浸 C 扫的"量身定做"市场

水冷板完美命中水浸 C 扫的所有强项，几乎是量身定做：
  1. 平板形 → 水浸 C 扫最爱扫的形状（放进水槽 X-Y 扫描就行）
  2. 铝合金 → 声速高、晶粒细，C 扫信号清晰
  3. 要查"结合面质量分布" → 正是 C 扫的看家本领（出钎着率分布图）
  4. 要出报告给车厂/数据中心看 → C 扫图直观，客户秒懂，A 扫波形客户看不懂
  5. 量产件 → 自动化扫描，一晚上扫几十块
  6. 能自动算钎着率 → 软件自动识别焊好区/虚焊区，扣除流道面积，直接出百分比

（6）一个关键技术点：C 扫怎么"扣除流道"

水冷板表面看起来是平的，但内部有流道（空的）和筋（实的）。算钎着率时，流道那块本来就没有结合面，不能算进"未焊"里。你们软件的功能就是：先识别出流道区域（从设计图或从扫描数据提取），只在"该焊的筋区"算钎着率。这样出的数字才准。

对销售的意义：这个"自动扣除流道、算钎着率"的功能，是打动车厂和数据中心客户的核心卖点——别家可能只会扫图，你们能直接出"钎着率 87.3%"这种数字报告。
客户对话（高频场景）
客户（电池厂）："我们做液冷板，怎么证明钎焊质量？"
"水浸 C 扫是目前最主流的方案。我们扫一张整板的钎着率分布图给您——红色是虚焊区、绿色是焊好的，还能自动扣除流道面积，直接算出钎着率百分比。要不要寄一块样板来，我们扫完出张报告给您看效果？"
客户（数据中心）："AI 服务器液冷板虚焊一颗 GPU 就烧了，能检出多小的缺陷？"
"我们水浸 C 扫配高频聚焦探头，能识别 0.1~0.3mm 级别的虚焊和空洞。整块板扫一遍出图，哪里有隐患一清二楚。建议做 100% 全检，AI 服务器这玩意儿出不起事故。"
记住这条市场定位：
"新能源 + AI/数据中心 + 电力电子" 的热管理检测 = 你们水浸 C 扫当下的黄金赛道。
水冷板是入口，进去后还能延伸到 IGBT 散热器、储能液冷板、溅射靶材——这些技术逻辑全是"查结合面质量"。

2.5 钛合金 / 铜合金

✈️钛合金件
航空发动机叶片、飞机承力件、医疗植入物（钛骨头）、化工耐蚀设备。钛合金细晶，UT 极好检（声速 6100~6200 m/s）。
🪙
铜合金件
铜管（空调、热交换器）、黄铜阀门、青铜轴承。铜的声速低（4400~4660）、晶粒粗，UT 中等难度。

三、"什么体"是什么？（铁素体/奥氏体/马氏体…）

你被这些词绕晕了。别怕，我用一个比喻让你彻底搞懂。

3.1 一个比喻搞懂"组织"

"组织"就是金属内部原子的"排列队形"。

想象一个广场上站着一群人（原子）。这群人可以站成不同的队形：
• 队形 A（铁素体）——大家站得松，队伍软，容易被推开
• 队形 B（奥氏体）——大家挤得紧，队伍灵活有弹性
• 队形 C（马氏体）——大家被强行卡在别扭的姿势，整个队形又硬又紧绷

同样是一群人（同样都是铁原子+碳原子），站成不同队形，性格完全不同。这就是"组织"决定"性能"。

3.2 五大组织速记（只要记住性格）

组织（队形）性格（一句话）对 UT 的影响
铁素体软、韧、有磁性细晶时好检
奥氏体韧、无磁性、耐腐蚀焊缝晶粒粗大 → 难检！
珠光体硬度适中、综合性能好好检（声速最高）
马氏体极硬、极脆、内应力大能检，但内应力干扰声速
渗碳体极硬极脆（铁碳化合物）作为珠光体的一部分存在
你只需要记住一条：客户提到"奥氏体"（比如 304、316 不锈钢），你脑子里就响警报——"粗晶、难检、要小心"。其他几个组织对销售来说不关键。

四、什么材料，是什么"体"？好不好检？

这一节是最实用的——客户报出材料名，你就能判断"好不好检"。

4.1 钢铁类

4.3 ★ 好检/难检 一张总表（贴墙）

✅ 你们水浸 C 扫 / A 扫 的主场（细晶材料）：
  • 铝及铝合金——声速高、晶粒细，UT 极清晰
  • 复合材料（碳纤维/玻璃钢/蜂窝）——分层/脱粘检测是 C 扫拿手好戏
  • 普通碳钢、压力容器钢（Q235/Q345/Q345R）——铁素体+珠光体，好检
  • 合金结构钢锻件（42CrMo 等）——调质后细晶，好检
  • 钛合金——细晶，好检
❌ 难检（要小心，可能不是你们最优解）：
  • 奥氏体不锈钢焊缝（304/316 焊缝）——粗晶草状回波，是 UT 公认最难点
  • 灰铸铁——片状石墨严重衰减声波
  • 紫铜、黄铜焊缝——粗晶
  • 大厚度镍基合金焊缝/堆焊层——粗晶
客户对话
客户："我们做碳纤维板的，想检测有没有分层。"
这正是你们水浸 C 扫的强项！你可以自信地说："分层检测是水浸 C 扫最核心的应用。我们扫一张 C 扫图给您看——分层在哪个位置、面积多大，一目了然。要不要寄个样件来我们扫一下出张图？"

五、奥氏体能测吗？水浸 C 扫能测吗？

5.1 哪些工件是"奥氏体"？

"奥氏体"在工程语境里，99% 指 304/316 系列不锈钢。客户嘴里说"奥氏体不锈钢"，基本就是说 304/316。常见场景：
  • 化工厂的管道、储罐、反应釜（不锈钢耐腐蚀）
  • 食品/制药/医疗设备（不锈钢易清洁、不生锈）
  • 低温储罐（液氮液氢，奥氏体低温不脆）
  • 核电、海洋工程的不锈钢结构件

5.2 能测吗？分两种情况

情况UT 能测吗你们水浸 C 扫能测吗说明
奥氏体母材
（不锈钢板/管/锻件本身）		✅ 能测，中等难度✅ 能测固溶处理后晶粒较细，常规 UT 可行。测厚度、测夹杂、测腐蚀都没问题。
奥氏体焊缝
（不锈钢焊过的接头）		⚠️ 极难⚠️ 不是最优解焊缝柱状晶粗大+各向异性，草状回波严重。这块市场主要靠 PAUT/TOFD。

5.3 为什么焊缝这么难？

奥氏体母材像一池平静的水，声波能顺畅穿透。但焊缝经过高温熔化再凝固，长出粗大的柱状晶（像一捆竖立的筷子），声波穿过就像手电筒光穿过浓雾——被四面八方散射，屏幕上一片杂乱的"草状回波"，把真正的缺陷信号淹没了。
对你们产品的诚实定位：
客户拿来奥氏体母材（不锈钢板/管/锻件，未焊接或焊缝周边）——你们 A 扫 + 水浸 C 扫完全能做。
客户专门要求奥氏体焊缝探伤——坦诚说明这是难点，常规 A 扫/C 扫不是最优，业内主流用 PAUT/TOFD。
这不是你们设备的缺陷，而是所有常规 UT 在这个工况都难。

六、HV 是什么？硬度指标全家桶

硬度（Hardness）就是"材料抵抗被压出印子的能力"。

拿一个硬东西（金刚石或钢球）用力压材料表面，压出的印子越小，说明材料越硬。HV、HB、HRC 都是测出来的数值，只是用的压头和算法不同。
代号全名用什么压用在哪
HV维氏硬度 Vickers金刚石四棱锥实验室、薄层、科研。范围广，最精确
HB布氏硬度 Brinell钢球软钢、铸铁、有色金属（粗略）
HRC洛氏硬度 Rockwell C金刚石圆锥淬火件、硬质材料（工厂最常用）
对照感觉（都是近似）：
  • 低碳钢（铁素体）：HV 100~150（HB ~120）
  • 珠光体钢：HV 200~280
  • 调质钢（42CrMo 回火索氏体）：HV 280~400（HRC 28~42）
  • 马氏体（淬火态）：HV 600~900（HRC 55~65）——这就是马氏体极硬的原因
  • 工具钢/高速钢淬火：HV 800~1000
看到 HV/HB/HRC，你只要知道"数字越大越硬"就够了。马氏体 HV 600~900 = 比普通钢硬 5~8 倍，所以又硬又脆。

七、C 扫描好在哪？（你们主力，重点讲）

7.1 先搞懂 A 扫 / B 扫 / C 扫的区别

用医学影像类比，一秒搞懂：
A 扫 = 心电图——一个点的波形上下跳动，只有专业人员看得懂。
B 扫 = B超切片图——看到工件内部一个纵截面（切开一刀看到的样子）。
C 扫 = 俯拍地图/热力图——从上往下看，工件某一深度层的全貌，像天气预报那种彩色图。
显示方式看到什么类比谁用
A 型单点波形（横轴时间、纵轴幅度）心电图所有 UT 仪器都有，最基础
B 型纵截面图（侧视切片）医学 B 超PAUT、TOFD 常用
C 型俯视深度切片图（像热力图）俯拍地图水浸 C 扫、PAUT

7.2 ★ 水浸 C 扫描的五大优势

  1. 耦合极稳定——工件泡在水里，水就是耦合剂。没有手动按压的压力波动，数据重复性极好。
    对比：接触式 A 扫靠人手压探头，压力大小影响耦合，数据波动大。
  2. 聚焦分辨率高——水里可以用聚焦探头，把声束聚成很细的焦点，横向分辨率远超接触式。
    能检出更小的缺陷，分层边界更清晰。
  3. 出图像，客户爱看——C 扫输出一张彩色俯视图（红=缺陷大、蓝=正常），缺陷位置、面积、分布一眼看清。
    A 扫只有一个波形，客户看不懂；C 扫图客户秒懂——这就是销售利器。
  4. 适合批量+自动化——探头按 X-Y 栅格自动扫查，一晚上扫一整片板，无需人工逐点。
    客户做量产件（航空板、汽车件）最爱这种自动化。
  5. 可深度切片——在不同深度设"闸门"，扫出多张 C 扫图，看缺陷在哪个深度层。

7.3 ★ C 扫描最适合检哪些工件

C 扫强项通俗讲典型工件（你们的客户）
分层检测材料内部一层层分开碳纤维板、玻璃钢板、轧制钢板
脱粘检测两层东西没粘牢蜂窝夹芯板、金属复合板、贴片件
孔隙检测里面有小气泡复合材料成型件
冲击损伤（BVID）外表没事里面坏了飞机蒙皮、复合材料壳体
厚度测绘整片扫厚度分布铝板、钢板、管材壁厚
焊缝/腐蚀扫查大面积成像平板焊缝（非奥氏体）、腐蚀区域
一句话总结你们产品的最强战场：
"细晶材料 + 平板/中小件 + 要看缺陷分布图 → 水浸 C 扫是王者"
铝板、复合材料板、蜂窝板、金属复合板——这些就是你们最该攻的市场。

7.4 PAUT / TOFD / C 扫 对比（被问到时怎么答）

方法原理强在哪弱在哪谁的市场
常规 A 扫单探头单角度简单、便宜、便携不出图、依赖人、定性难你们（主力）
水浸 C 扫水槽+栅格扫查出图、分辨率高、耦合稳、自动化大件泡不下、粗晶材料弱你们（主力）
PAUT 相控阵多晶片电子控制角度一次多角度成像、效率高、适合复杂焊缝设备贵、粗晶仍受限压力容器/管道焊缝（你们没有）
TOFD用缺陷尖端衍射波测高精确、对面状缺陷（裂纹）特灵上下表面有盲区、要配 PAUT厚壁焊缝裂纹（你们没有）
PAUT/TOFD 对粗晶（奥氏体焊缝）有多大提升？
有提升，但不是万能。PAUT 能用聚焦把能量集中，提升信噪比约 6~12 dB；TOFD 对裂纹检出有优势。但粗晶散射是物理硬伤，即使 PAUT 也无法完全解决，要用专门低频纵波相控阵 + 声束模拟。所以业内常说"奥氏体焊缝是无损检测的皇冠"，能用但很难。
关键认知：C 扫对奥氏体焊缝有帮助吗？
帮助有限。C 扫的优势是成像和耦合稳定，但奥氏体焊缝的根本问题是粗晶散射，水浸 C 扫换不解决这个问题。C 扫对细晶材料（铝、钢、钛、复材）才能发挥全部优势。
客户对话（被问"你们能不能测焊缝/能不能替代 PAUT"）
客户："你们这个水浸 C 扫能测压力容器焊缝吗？"
"压力容器焊缝（碳钢/低合金钢）我们 A 扫完全能做，C 扫也能扫出焊缝缺陷分布图。但如果是奥氏体不锈钢焊缝，常规 UT 都比较困难，业内一般推荐 PAUT。我们的强项是铝板、复合材料、分层脱粘这块，要不要我针对您的工件出个方案？"

📋 全文总结（12 条记住就够）

  1. 五大加工：铸造（倒模）、轧制（擀面）、锻造（打铁）、机加工（切削）、焊接（熔接）。每种产生不同缺陷。
  2. 加工→缺陷：铸→缩孔气孔；轧→分层；锻→白点；焊→裂纹未熔合；热处理→淬火裂纹。
  3. "什么体"就是组织（原子排列队形）。你只需记：奥氏体 = 粗晶难检，其他不用深究。
  4. 304/316 不锈钢 = 奥氏体。母材能测，焊缝极难（粗晶草状回波）。
  5. 铝 = 你们黄金客户：声速高、晶粒细、UT 极清晰。航空铝、铝型材、汽车铝都是。
  6. 复合材料 = 你们杀手锏市场：碳纤维/玻璃钢/蜂窝板，C 扫查分层脱粘是强项。
  7. 水冷板 = 你们当下核心市场：新能源车电池液冷板、AI/数据中心液冷板、IGBT 散热器。铝板+钎焊/FSW，查钎着率是核心。
  8. 钎着率 = 钎焊面焊实的比例。虚焊空洞导致散热死角→电池热失控/芯片烧毁。车厂和数据中心有硬指标（常见 ≥85%）。
  9. HV = 维氏硬度，数字越大越硬。马氏体 HV 600~900（极硬极脆）。
  10. A 扫=心电图，C 扫=俯拍地图。C 扫出图、耦合稳、分辨率高、能自动化、能算钎着率。
  11. 水浸 C 扫最强战场：细晶材料 + 平板/中小件 + 要看缺陷分布/结合质量。铝、复材、分层、脱粘、钎着率。
  12. 奥氏体焊缝是盲区：坦诚说明，建议 PAUT。这不是你们设备差，是所有常规 UT 都难。
这份教材读完后，你应该能：客户报出材料名（铝/钢/304/碳纤维…），你立刻知道好不好检、用什么方法、你们设备行不行。

📝 随堂测验（10 题）

这 10 题考的是"懂不懂客户拿来的是什么、能不能测"。做完整再看解析。
1客户拿来一块"碳纤维板"想检测有没有分层，你们水浸 C 扫能做吗？
A. 不能，碳纤维不是金属
B. 能，而且这正是水浸 C 扫的强项
C. 能，但效果很差
D. 只有 PAUT 能做
✅ 选 B。分层检测是水浸 C 扫的核心应用。复合材料（碳纤维、玻璃钢、蜂窝板）的分层、脱粘、孔隙，正是 C 扫的看家本领。这是你们产品的杀手锏市场。
2客户说工件是"304 不锈钢焊缝"，要 UT 探伤。你应该？
A. 没问题，常规 A 扫就能搞定
B. 不锈钢都不能测
C. 坦诚说明奥氏体焊缝是难点，常规 UT 不是最优，业内主流用 PAUT/TOFD
D. 调高频率就能解决
✅ 选 C。304 是奥氏体不锈钢，焊缝处粗大柱状晶产生草状回波，是 UT 公认最难点。常规 A 扫/C 扫都不是最优解。A 错（焊缝难）；B 错（母材能测，是焊缝难）；D 完全反了（频率越高衰减越大越糟）。
3铝件做 UT 检测，难度大概如何？
A. 优（声速高、晶粒细）
B. 差（铝太软声波进不去）
C. 中（粗晶难检）
D. 铝不能用 UT 测
✅ 选 A。铝声速 6300 m/s（比钢还快），晶粒细、衰减小，UT 非常清晰。航空铝、铝型材、汽车铝都是水浸 C 扫的黄金客户。
4"马氏体 HV 600~900"——HV 是什么？
A. 一种声速单位
B. 维氏硬度（数字越大越硬）
C. 韧性指标
D. 温度单位
✅ 选 B。HV 是维氏硬度，用金刚石四棱锥压材料表面测出。马氏体 HV 600~900，比普通钢（HV 100~150）硬 5~8 倍，所以极硬极脆。同类还有 HB（布氏）、HRC（洛氏）。
5水浸 C 扫相比接触式 A 扫，最大的优势是什么？
A. 设备更便宜
B. 能测更大的工件
C. 耦合稳定 + 出图像 + 分辨率高 + 可自动化
D. 不用水，更方便
✅ 选 C。水浸 C 扫四大优势：①水耦合稳定（无人工压力波动）②聚焦分辨率高 ③出 C 扫图客户秒懂 ④可自动化批量扫。A 错（C 扫更贵）；B 错（大件泡不下，反受限于水槽）；D 完全反了（水浸就是要泡水里）。
6下列哪个工件/材料，是你们水浸 C 扫的最核心战场？
A. 304 不锈钢焊缝
B. 大型灰铸铁机床床身
C. 长输天然气管道
D. 碳纤维复合材料板的分层检测
✅ 选 D。复合材料分层检测是水浸 C 扫的杀手锏。A（奥氏体焊缝）是盲区；B（灰铸铁大件）衰减大且泡不下；C（长输管道）用导波或 PAUT，水浸做不了。
7客户说工件是"锻件"，你脑子里应该跳出什么典型缺陷？
A. 分层
B. 白点（氢致微裂纹）
C. 缩孔
D. 咬边
✅ 选 B。锻件最可怕的典型缺陷是白点（氢造成的内部微裂纹），还有夹杂、折叠。A 分层是钢板的毛病；C 缩孔是铸件的毛病；D 咬边是焊缝的毛病。
8【销售场景】客户问："C 扫和 PAUT 哪个好？"最佳回答思路？
A. 各有强项：C 扫强在细晶平板件成像（铝/复材/分层），PAUT 强在复杂焊缝多角度成像
B. C 扫绝对比 PAUT 好
C. PAUT 绝对比 C 扫好
D. 它们是一回事
✅ 选 A。两种方法定位不同，不存在绝对优劣。C 扫适合细晶平板件（铝、复材、分层脱粘）的成像扫查；PAUT 适合复杂焊缝的多角度快速成像。专业的销售要懂扬长，而不是贬低对手。
9水冷板（液冷板）检测，最核心的检测指标是什么？
A. 表面粗糙度
B. 板的厚度
C. 钎着率（钎焊面焊实的比例）
D. 材料成分
✅ 选 C。钎着率是水冷板最核心的指标。虚焊/空洞区散热差，会导致电池热失控或芯片烧毁。车厂和数据中心有硬指标（常见要求 ≥85%）。水浸 C 扫能自动识别焊好区/虚焊区并扣除流道面积，直接算出钎着率百分比。
10【销售场景】电池厂客户问："液冷板钎焊质量怎么验证？" 最佳回答？
A. "用射线拍片就行"
B. "肉眼看不出来，没办法检"
C. "只能切开看金相"
D. "水浸 C 扫扫一张钎着率分布图，自动扣除流道面积出百分比报告"
✅ 选 D。这是水浸 C 扫对水冷板的核心卖点——无损、出图、自动算钎着率。A 射线对结合面不敏感（厚度方向重叠）；B 太消极（明明能检）；C 破坏性，量产件不能切。最佳做法是建议客户寄样板，扫一张图出报告看效果。
